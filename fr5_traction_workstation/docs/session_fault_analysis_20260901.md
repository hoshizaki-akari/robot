## 软件修复

- 目标力进入正负0.5N死区时立即把轴向速度和积分清零。
- 力误差改变符号时立即丢弃上一方向的残余速度，再向正确方向补偿。
- 反馈超过0.25秒未更新时先发布停止命令；只有持续超过0.8秒才锁定故障。
- 直驱层的旧速度命令有效期缩短到0.25秒，避免SDK阻塞恢复后的第一帧继续执行旧命令。
- 增加四个FR5反馈RPC的分项耗时日志，后续可直接判断是哪一个SDK调用发生阻塞。
- 页面不再把“重新校零换新记录”显示成异常牵引；异常记录增加简短中文原因。
