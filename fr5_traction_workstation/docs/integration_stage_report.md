# FR5 牵引工作站集成检查报告

日期：2026-08-31

## 已通过

- FR5 SDK 与真实机械臂建立连接，读取到 6 个关节的实时角度。
- KWR75D 的真实 Wrench 已发布，坐标系为 `base_link`；现场读取到有限的力/力矩数值。
- `joint_state_broadcaster`：active。
- `force_torque_sensor_broadcaster`：active。
- `cartesian_velocity_controller`：inactive，等待方向锁定后由牵引管理器接管。
- 牵引管理器 READY 状态、松绳基线校零按钮、MANUAL_SETUP 联锁均已在真实 ROS 数据下验证。
- 独立网页已启动并登录验证：实时 FR5 三维模型、三轴力分量、通信状态和流程按钮均正常。
- 目标力输入限制为 1～30N；当前现场验收上限为 15N。

## 当前现场检查点

状态已经通过网页的“松绳校零并准备”进入 `MANUAL_SETUP`。接下来必须由操作者使用
法奥官方示教器，只做 X/Y/Z 平移、保持法兰方向不变，把当前松绳逐步张紧；张紧后
保持法兰静止，再点击“确认并锁定方向”。系统会用 `base_link` 下的实时力向量锁定
牵引方向，之后才允许开始恒力牵引。

## 现场注意

- 启动时 Fairino SDK 的硬件零点接口返回代码 60，因此没有强行把硬件零点当作成功；
  系统按流程在松绳准备时采集软件基线，避免把重力/安装偏置误判为绳张力。
- 当前没有执行自动牵引和 1～15N 恒力验收，因为方向还没有由现场张紧动作确认；
  在这个检查点继续自动运动会绕过操作者对绳路和方向的人工确认。
