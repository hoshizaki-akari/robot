# FR5 牵引工作站集成与现场验证报告

日期：2026-09-01
机器人：FR5（192.168.58.2）
力传感器：KWR75D
力坐标系：`base_link`

## 软件侧已完成

- 使用 `fr5_direct_driver_node.py` 作为唯一 Fairino SDK 连接者，以 25Hz 读取真实
  关节、末端位姿和 Wrench，并以 25Hz ServoCart 发送牵引增量；这是针对现场
  SDK RPC 阻塞特性验证后的稳定频率。
- 管理器在“松绳准备”时采集软件基线，发布 `/traction/corrected_wrench`；控制器、
  网页和记录统一使用减去安装/重力偏置后的力数据。
- 根据工具 Y− 实体张紧结果修正 FR5 当前现场 ServoCart 基坐标增量方向，配置项为
  `base_servo_sign: 1.0`；此前的 `-1.0` 会让 5N 恒力启动沿反方向放松绳带。
- 针对实体 ServoCart RPC 偶发短暂阻塞，将 Wrench/末端状态超时调整为 500ms，
  控制器健康超时为 600ms，仍保留过期数据停机保护。
- 方向锁定后允许设置和启动 1～20N；没有成功设置目标力时禁止开始，避免误用默认
  目标。20N 仍需独立实体验收，不能因解除软件闸门而视为通过。
- 校准最低受力单独设为 0.5N；自动 Y− 张紧仍要求稳定约 1.5N，最大 30mm，超过
  10N立即停止搜索。
- 增加“设置零点”和“回零”，控制器/硬件/力数据超时及异常输入保护
  保留。
- 修复启动脚本对 ROS2 严格模式和 launch 参数格式的兼容问题；“校零”现在
  可在 `READY`、`MANUAL_SETUP`、`COMPLETED` 重复使用。“回零”会回到保存的松弛
  零点，并在服务调用时读取当前距离保护参数，避免参数被修改后仍使用旧缓存值。
- 网页 `090105.html` 已接入真实 FR5 关节状态、三轴力向量、受力方向/增力方向和流程。
