# FR5 牵引工作站集成与现场验证报告

日期：2026-09-01
机器人：FR5（192.168.58.2）
力传感器：KWR75D
力坐标系：`base_link`

## 软件侧已完成

- 使用 `fr5_direct_driver_node.py` 作为唯一 Fairino SDK 连接者，100Hz 读取真实
  关节、末端位姿和 Wrench，并以 ServoCart 发送牵引增量。
- 管理器在“松绳准备”时采集软件基线，发布 `/traction/corrected_wrench`；控制器、
  网页和记录统一使用减去安装/重力偏置后的力数据。
- 修正了 FR5 当前现场 ServoCart 基坐标增量与实测位姿方向相反的问题，配置项为
  `base_servo_sign: -1.0`。
- 方向锁定后允许设置 1～30N；没有成功设置目标力时禁止开始，避免误用默认目标。
- 校准最低受力单独设为 0.5N；自动 Y− 张紧仍要求稳定约 1.5N，最大 30mm，超过
  10N立即停止搜索。
- 增加“设置当前位置为零点”和“低速回零”，控制器/硬件/力数据超时及异常输入保护
  保留。
- 网页 `090105.html` 已接入真实 FR5 关节状态、三轴力向量、受力方向/增力方向和流程。

## 自动与真实数据验证

- C++ 回归测试：5/5 通过（数学、状态机、控制器、安全、合成流程）。
- Python/UI 测试：4/4 通过；`ruff` 与 Python 编译检查通过。
- 真实 FR5 SDK 反馈稳定约 100Hz；旧版本约 1Hz 的 ServoJ 阻塞导致的
  `EE_STATE_TIMEOUT/WRENCH_TIMEOUT` 已排除。
- 末端工具 Y− 张紧搜索曾成功三次：1.53N/9.40mm、1.58N/12.12mm、
  1.91N/29.35mm。
- 在去零点力接入控制器前的一轮 5N 牵引中，数据连续约 100Hz，但控制器使用了
  原始力偏置，最终记录为 6.97N、44.8mm、`WRENCH_TIMEOUT`；该问题已修复，记录为
  `session_1788228223340`。
- 修复后再次进行的 Y− 搜索因前一次失败牵引已改变实体测试物位置，走满 30mm 未达到
  稳定张力；系统按限位停止，没有继续盲目扩大位移。

## 需要人工完成的唯一事项

请把带子另一端和测试目标恢复到最初的固定关系，确认当前末端位姿下绳带确实松弛；

通过继续加大位移安全地猜测方向。
