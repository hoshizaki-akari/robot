# 实时方向纠偏 V1.0 开发记录

## 当前结论

V1.0 已完成“算法模块 + ROS2 消息链 + shadow 模式”开发。默认配置为
`direction_correction_mode: shadow`，因此算法会计算并记录侧向纠偏量，但不会
向真实 FR5 发送侧向速度。只有完成实体方向符号检查后，才允许把配置改成
`active`。

本次实体复测还修复了 FR5 反馈链路的一个实际问题：运动 RPC 与反馈发布原先在
同一个 Python 回调中，`ServoCart` 的短时阻塞会同时拖住力、位姿和健康心跳，造成
误报 `ROS2_CONTROL_ERROR` 或 `WRENCH_TIMEOUT`。现在反馈发布循环与运动循环分离；
FR5 力、校正力、位姿和关节状态链路统一使用可靠 QoS，短时运动调用不会再阻断
反馈。控制器在反馈恢复后也会从一次安全暂停中自动恢复，不会永久锁死当前命令。

## 处理链

1. manager 先用松弛校零后的 `base_link` 力矢量作为输入。
2. 锁定方向 `d0` 保持不变，不随每个瞬时采样漂移。
3. 张力大小使用 `T = ||F||`；方向使用单位向量 `u = F / ||F||`。
4. 用 7 点球面 medoid（单位向量中值）抑制单个跳点。连续方向变化会在
     7 个采样窗口后进入快滤波器，因此不会被单点中值永久吞掉。
5. 快滤波器默认 4 Hz，慢滤波器默认 0.6 Hz。快、慢方向之间的夹角和快方向
   相对 `d0` 的夹角共同作为变化证据。
6. 校准窗口估计角度的 MAD。进入纠偏阈值为
   `max(3 deg, median + 4 * 1.4826 * MAD)`，退出阈值为进入阈值的一半且不低于
   1.5 deg。这样阈值会随传感器静态噪声变化，但不会低到追逐量化噪声。
7. 变化证据连续默认 0.15 s 才进入 `CORRECTING`；力过小或方向反向则进入
   `SENSOR_HOLD`，侧向指令为零。
8. 纠偏在锁定方向的切平面 `b1/b2` 中进行。切向误差为
   `e = [b1·(F - (F·d0)d0), b2·(F - (F·d0)d0)]`。
9. 侧向响应矩阵使用阻尼最小二乘：
   `q = J^T (J J^T + lambda^2 I)^-1 e`，
   `v_tangent = -K q`。负号表示沿“消除侧向力”的方向移动；控制器最后再
   把切向速度变回 `base_link`。
10. V1.0 默认侧向速度上限 0.5 mm/s，纠偏累计位移上限 3 mm，且只在
    `CORRECTING/SETTLING` 状态输出；单点跳变、反向力、失去新鲜力数据都不动。

## 当前 FR5 响应参数

2026-09-02 固定目标 base X/Y 小范围测试得到（原始单位 N/mm，配置换成 N/m）：

```text
J_base_xy = [[ 6.47, 5.84 ],
             [10.79, 0.76 ]] N/m
```

每次方向锁定后，程序将这个 base X/Y 矩阵转换到当前锁定方向对应的
`b1/b2` 坐标；不会把 base 坐标矩阵直接当作切向矩阵使用。
