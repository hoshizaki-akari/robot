# FR5 侧向纠偏正负号实机校核（2026-09-02）

## 结论

固定目标条件下，Base X/Y 两个平移方向都会改变与绳方向正交的侧向力，且存在明显交叉耦合。因此不能使用“Fx 只控制 X、Fy 只控制 Y”的独立正负号规则，应使用实测二维响应矩阵的阻尼伪逆计算纠偏位移。

锁定牵引方向（base_link）：

```text
d = [-0.152628, 0.050882, 0.986973]
```

以该方向投影后的侧向力 `L = F - (F·d)d` 为输出，实测局部响应矩阵为：

```text
[dLx]   [0.006471  0.005841] [dx]
[dLy] = [0.010793  0.000765] [dy]
```

单位为 N/mm，`dx`、`dy` 使用 Base X/Y 位移。矩阵条件数约 2.99，在本次位姿附近可逆。四个主系数均为正，但 Y→Ly 通道很弱，接近传感器噪声量级，不能单独依赖其符号。

推荐在线控制律：

```text
delta_p = -gain * (J^T J + lambda^2 I)^-1 * J^T * lateral_error
```

实现时应使用 0.2–0.5 mm 的单周期位移上限、方向变化滞回、低通后的侧向力，以及在线小扰动更新 J；禁止把本次矩阵作为所有位姿下永久不变的常数。

## 过程与异常

- 松弛零点初始张力约 0.02 N。
- Tool Y- 自动搜索共经历较长松弛行程，最终在约 1.5 N 处停止。
- 方向校准成功，角度 p95 为 8.08°。
- 恒力控制真实达到 5 N，并在约 8 秒内主要保持在 4.986–5.017 N。
- 随后出现一次 `WRENCH_TIMEOUT`，控制器按设计停止。横向端点测试在轴向力控关闭后，以低速位置运动完成，所以端点轴向力存在 4.18–5.01 N 的漂移；矩阵计算已去除锁定方向上的轴向分量。
- 测试结束后，机械臂以位置驱动返回已保存的松弛零点，最终张力为 0 N，未在张紧状态重新校零。
