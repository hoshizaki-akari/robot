# 真实绳带张紧验收（用户现场操作）

当前软件已经连接真实 KWR75D，并在当前松绳位姿稳定显示“绳带松动”。下面只验证
从松到紧、方向和松回，不做自动运动。

## 开始前

- 保持现在的法兰朝向，不做旋转。
- 只用示教器沿 `base_link` 的 X+/X-/Y+/Y-/Z+/Z- 单轴小步平移。
- 第一次只拉到约 1–3 N，不要为了测试报警故意超过 10 N。
- 固定物会发生小移动，拉力大时可能被提起；发现物体明显移动或悬空就停止继续增力。
- 保持物理急停可触及。

## 操作顺序

1. 打开 <http://127.0.0.1:8092>，确认右上角是“真实传感器已连接”。
2. 确认绳带松动并点击“设为松绳基线”。
3. 等约 3 秒，页面应稳定显示“绳带松动”，方向区域应显示 `--`。
4. 选一个单轴方向，用示教器小步平移：
   - 运动时页面应显示“机械臂移动中”，数值和曲线仍会变化，但暂不下松紧结论。
   - 停止后页面先显示“正在停稳”，稳定牵引力达到 1 N 后显示“绳带已张紧”。
5. 记录页面上的：
   - 合力（N）
   - Fx/Fy/Fz
   - “传感器测得受力方向”
   - “估算增力运动方向”
6. 核对“估算增力运动方向”是否与您刚才让拉力增大的实际移动方向一致：
   - 一致：保留当前设置。
   - 完全相反：点击一次“反转增力方向”，再用小力复核。
7. 反向小步移动，让绳带重新松开。停稳后应在约 0.5 N 以下恢复“绳带松动”，方向再次变为 `--`。
8. 换一个单轴方向重复小力验证。每次只做一个轴，不组合移动。

## 立即停止的情况

- 合力接近或超过 10 N。
- 固定物被明显提起、滑动或翻转。
- 法兰朝向变化超过 1°，页面提示基线无效。
- 页面显示数据断开、延迟持续增大或更新频率明显下降。
- 页面方向与实际现象无法解释。

## 需要反馈给开发的信息

请告诉我以下四项即可继续收口本阶段：

1. 从松到紧时，页面是否依次出现“移动中 → 停稳 → 张紧”。
2. 张紧时的合力、Fx/Fy/Fz 和两个方向标签。
3. 松回后是否恢复“松动”。
4. “增力运动方向”是否需要点击反转。
