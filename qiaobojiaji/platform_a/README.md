# 跟骨撬拨夹挤微创复位辅助机器人控制软件 V1.0

本项目是用于软件著作权材料整理、教学和离线演示的桌面软件原型。软件通过仿真设备接口展示术前参数录入、撬拨定位、夹挤复位、六维力监测、状态联锁、急停、日志和报告导出等流程。

> 重要：本原型未经医疗器械注册、临床验证或风险管理确认，不得用于真实患者诊疗或直接驱动临床设备。

## 运行

要求 Python 3.10 或更高版本，无第三方运行依赖。

```bash
python main.py
```

演示账号：`operator`，密码：`demo123`。

## 真实设备接入边界

界面保持最初原型结构，不增加模式选择框或设备状态面板：

- 默认在后台从 `http://127.0.0.1:8765/api/state` 读取真实快照。
- 真机模式只开放“开始夹挤复位”用于检查视觉计算结果；它不会发送使能、运动或夹爪命令，其余控制按钮禁用。
- AG95 未完成开口标定前只显示 `0～1000` 原始位置。
- 当前 TCP 是控制器工具定义，不冒充夹爪指尖或治疗作用点。

## 第一阶段：夹挤视觉预检查

- YOLO 只识别足跟，不训练针模型。
- 针还插着时，用露出的针与足跟边缘的交点确定针孔；针被取下时，尝试寻找足跟上的针孔黑点。
- 绿色区域表示足跟，黄色横线两端表示左右夹取点，红色十字表示针孔。
- 深度相机给出相机坐标。相机与机械臂的手眼标定已经完成并通过独立验收，结果保存在 `platform_a/config/handeye_calibration.json`。
- 当前夹挤预检查会把相机坐标转换为机械臂基座坐标，但仍不会自动运动；夹爪相对法兰的安装偏移和真实夹挤动作还要单独确认。
- “夹挤位移”表示夹爪接触足跟后继续向内闭合的距离。

只检查识别结果：

```bash
python scripts/check_platform_a_clamp.py
```

如需运行最初的离线演示，可临时使用：

```bash
PLATFORM_A_DEVICE_MODE=simulation python main.py
```
