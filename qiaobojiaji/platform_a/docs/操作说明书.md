# 跟骨撬拨夹挤微创复位辅助机器人控制软件 V1.0 操作说明书

## 一、软件概述

本软件面向跟骨骨折撬拨、夹挤微创复位辅助机器人的科研、教学和软件流程演示。软件在统一工作台内提供用户登录、病例任务、参数规划、仿真设备连接、撬拨定位、夹挤复位、六维力监测、安全联锁、过程日志和数据导出功能。

本版本使用离线仿真设备接口，不向真实医疗设备发送指令。它未经医疗器械注册、临床验证或风险管理确认，不得直接用于患者诊疗。界面中的“急停”为软件级演示功能，不能替代真实设备的独立硬件急停。

## 二、运行环境与启动

运行环境为 Windows 10/11 x86_64，建议 Python 3.10 或更高版本。软件仅使用 Python 标准库。进入项目目录后执行 `python main.py`。登录窗口打开后输入演示账号 `operator` 和密码 `demo123`，点击“登录”进入主界面。登录失败时软件保留在登录页并给出提示。

## 三、主界面布局

主界面顶部显示软件名称、当前控制状态、连接和断开按钮。左侧依次为病例与任务、规划与安全参数、复位辅助控制。中部上方为二维术野与机器人运动示意，下方为六维力/力矩监测。右侧显示位置、任务进度、记录导出和事件日志。

状态栏可显示设备未连接、空闲、撬拨定位、夹挤复位、保持、已暂停、急停锁定和流程完成。操作者应在操作前确认状态，并结合事件日志判断指令是否被接受。

## 四、建立病例任务

1. 在“病例编号”中填写本次任务的唯一编号。
2. 在“患者编码”中填写去标识化编码，不建议录入姓名或身份证号。
3. 选择左侧或右侧，填写操作者账号。
4. 点击“建立病例”。日志显示“病例建立成功”后，控制流程方可启动。
5. 再次建立病例会清空内存中的上一任务采样，故应先导出上一任务记录。

## 五、连接仿真设备

点击顶部“连接仿真设备”。软件建立仿真适配器连接并使能仿真伺服，状态切换为空闲。点击“断开”可结束连接；当撬拨、夹挤、保持或暂停任务存在时，软件拒绝断开，操作者应先执行安全停止。

## 六、规划参数设置

撬拨位移允许 0～30 mm，夹挤位移允许 0～40 mm，速度允许 0.1～5.0 mm/s，力上限允许 5～150 N，力矩上限允许 0.5～15 Nm，保持时间允许 1～30 s。输入后点击“校验并应用参数”。输入非数字或超出范围时，软件显示参数错误且不替换当前有效参数。

参数只可在空闲或流程完成状态修改。控制过程中修改参数会被状态联锁拒绝。力上限和力矩上限属于本软件仿真的监测阈值，不代表任何真实临床安全值。

## 七、撬拨定位操作

确认病例已建立、仿真设备已连接、参数已应用且状态为空闲。点击“开始撬拨定位”，状态切换为撬拨定位。二维示意图中的撬拨器向目标方向运动，Z 位置、进度和六维力数值随周期刷新。到达目标撬拨位移后，软件自动进入保持阶段；保持时间结束后显示流程完成。

## 八、夹挤复位操作

确认系统为空闲或流程完成状态。点击“开始夹挤复位”，仿真夹爪开度逐步减小，X 行程和任务进度同步增加。二维示意图中的左右夹持端向中心靠拢。到达设定夹挤位移后进入保持阶段，保持结束后切换为流程完成。

## 九、暂停、继续和安全停止

在撬拨定位、夹挤复位或保持阶段点击“暂停”，状态切换为已暂停，位置保持不变。点击“继续”恢复暂停前的任务状态。点击“安全停止”会结束当前控制过程并返回空闲。急停锁定状态不能用安全停止解除，必须执行急停复位。

## 十、夹爪点动与软件回零

在空闲或暂停状态，可点击“夹爪张开 +1mm”或“夹爪闭合 -1mm”调整仿真夹爪开度。开度自动限制在 0～40 mm。软件回零仅可在空闲或流程完成状态执行，它将位置、力数据、进度和夹爪开度恢复到初始值。

软件零点可以由操作者重新记录：先把机械臂移动到希望的默认位置并确认停稳，在“软件回零”按钮上点击鼠标右键，或按 `Ctrl+Shift+H`，确认后保存当前位姿。保存文件为 `platform_a/config/home_position.json`；以后软件回零和夹挤复位默认返回这个位置。记录零点只读取状态，不发送运动命令。机械臂只要已经停稳、没有报警且夹爪已张开，即使流程记录和实际位置不一致，也会先抬高当前末端再返回软件零点，不再因位置偏差直接拒绝。

## 十一、六维力监测

界面显示 Fx、Fy、Fz 三轴力，Tx、Ty、Tz 三轴力矩，并自动计算三轴合力。数据由仿真适配器生成，用于展示界面刷新、趋势观察和越限处理。运行中若合力超过力上限，或合力矩超过力矩上限，控制器记录报警并进入急停锁定。

## 十二、急停与急停复位

点击“急停”后，软件立即撤销仿真伺服使能，状态显示急停锁定，后续运动启动受到禁止。排查触发原因后点击“急停复位”，软件重置仿真位置和力数据，重新使能并返回空闲。真实设备应用必须使用独立硬件安全链路，不能依赖本演示按钮作为唯一保护。

## 十三、二维示意与进度显示

二维区域展示跟骨形状、撬拨器和夹持端的抽象示意，不是医学影像，也不用于导航。撬拨高度取自 Z 位移，夹挤行程取自 X 位移。右侧进度条显示当前阶段完成比例，阶段切换时进度会重新计算。

## 十四、事件日志

事件日志按时间记录连接、断开、病例建立、参数应用、流程启动、暂停、继续、停止、完成、操作拒绝和报警。日志是操作者确认软件响应的重要依据。保存至磁盘的事件记录包含时间、级别和消息三个字段。

## 十五、过程记录导出

建立病例后，软件按照刷新周期采集状态、位姿、六维力和进度。点击“导出过程记录”，程序在 `data/病例编号/` 下生成 `case.json`、`events.json`、`samples.csv` 和 `复位过程报告.txt`。CSV 使用带 BOM 的 UTF-8 编码，可直接用常见表格软件打开。

## 十六、典型操作流程

启动软件并登录；建立去标识化病例；连接仿真设备；设置并应用规划参数；观察空闲状态；启动撬拨定位；按需暂停和继续；等待保持阶段完成；执行软件回零；启动夹挤复位；等待流程完成；检查日志和最大受力；导出记录；安全停止并断开设备；关闭软件。

## 十七、状态联锁说明

设备未连接时不能启动运动。病例未建立时不能启动撬拨或夹挤。控制任务运行期间不能修改参数、回零或断开设备。暂停状态允许继续、安全停止和夹爪点动。急停锁定时运动命令不可用，只有急停复位可以恢复。上述联锁由 `RobotController` 状态机统一实施。

## 十八、常见问题

无法启动控制时，先检查病例是否建立、设备是否连接、状态是否为空闲以及参数是否通过校验。登录失败时检查大小写并使用演示账号。界面无力数据时检查设备连接状态；空闲状态下数值会逐渐衰减。导出失败时检查是否已建立病例以及项目目录是否可写。触发急停后应查看日志中的越限数值，调整仅用于仿真的参数，再执行急停复位。

## 十九、退出软件

建议先安全停止当前任务，再点击断开按钮，确认状态为设备未连接后关闭窗口。若有需要保留的数据，应在关闭前导出。直接关闭窗口不会自动将内存中的采样写入病例文件夹。

## 二十、维护与版本说明

V1.0 实现离线仿真闭环及完整的软件操作流程。源代码按模型、设备适配、控制状态机、记录和界面分层。后续若接入 ROS2、机械臂、导航或真实力传感器，应新增独立适配器和配置，不应修改已验证的安全状态机行为；同时需要补充单元测试、集成测试、风险管理、网络安全、数据保护、可用性验证和医疗器械合规材料。
