## 网页实操

打开 http://127.0.0.1:8082/ 。必须显示机械臂、力传感器数据在线，再操作。

- 省力拖拽：选模式 → 绳子松弛、松手 → 初始校准 → 开始拖拽 → 沿工具 X/Y/Z 推拉 → 松手 → 结束拖拽。
- 位置牵引：选模式 → 松弛时初始校准 → 手动张紧并保持 → 方向确定 → 待方向锁定 → 选择目标力 → 开始牵引。到达目标后保持位置，不自动追力；结束按钮停止当前任务。
- 恒力牵引：同样先初始校准、手动张紧、方向确定、设目标，再开始。当前沿锁定方向分步调节，不声称已经验证自适应换向。

一轮结束后可再次设置目标、开始，不需要重复方向标定；新一轮有独立记录。安装、姿态、负载状态变化后需重新标定。

## 导出给复核

每种模式结束后在“牵引记录”中找到对应行，点击该行“导出日志”，发送原始 ZIP，不能只发“导出全部摘要”的 CSV。故障后也导出对应那一行。建议停止后等 10 秒再导出，以保留后续驱动反馈。

ZIP 内容：

- traction.csv：从校准/本次重新开始到终态的时序数据，区分命令速度与实测速度。
- summary.json：本轮模式、时间、目标、峰值、终态和停止原因。
- operations.csv：网页点击和返回结果，不能单独当作运动证据。
- runtime_feedback.jsonl：同期真实身份验证标志、关节位置/速度、驱动阶段、motion_idle、力、末端位置及数据年龄；最多包含结束后 10 秒上下文，可能与下一轮重叠。
- runtime_evidence.json：采样覆盖范围、数量及记录器状态。空数据不代表停稳。

旧 session 没有新增反馈时不会伪造或回填。运行记录保存在 debug/traction_sessions，后台反馈在 debug/runtime_feedback；各进程日志在 debug/session_*_workstation。

## 常驻启动

scripts/start_live_workstation.ps1 接受 -CalibrationFile（本机已验证的 WSL YAML 绝对路径）及 -Background。凭据必须从现有本机安全来源注入进程环境 AUBO_V4_HOST/PORT/USERNAME/PASSWORD，不写入仓库、命令参数或日志。本次使用的现场 YAML 位于 debug/session_20261019_hardware/live_commissioning.yaml，不能直接移植到其他安装姿态。

关闭网页标签不会结束后台。点击网页“关闭程序”会使网页组件退出，并由 supervisor 请求停止、退出其余组件。重新加载网页不会自动开始牵引。实体急停后的恢复遵循控制柜/示教器流程；页面“恢复说明”不解锁硬件。
