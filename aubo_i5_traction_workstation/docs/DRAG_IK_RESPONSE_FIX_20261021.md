# 拖拽故障及力量响应修复（2026-10-21）

## 输入与定位

输入日志：`session_1792486852166_full_log (1).zip`。

- 终止原因：`IK joint 6 delta 0.100573 rad exceeds 0.050000 rad continuity bound`，不是通信超时。
- 旧关节数组缩放仅处理不超过两倍步长（0.1 rad）的解；0.100573 rad 恰好越过旧处理范围。
- 力量分箱 1–5 / 5–10 / 10–15 / 15–20 / 20–30 N 中，命令速度中位数约为 0.028 / 0.062 / 0.131 / 0.175 / 0.200 m/s，但记录速度中位数只有约 0.014 / 0.018 / 0.013 / 0.016 / 0.016 m/s。此观察包含不同姿态、方向，不是标定后的速度曲线。
- 调度器共用 5 mm 目标前瞻上限，导致不同力度很快落在相似的目标距离上；仅提高控制器增益无法消除这一瓶颈。

## 修改

1. 生产配置改用 FK 锚定的自适应笛卡尔 IK：当关节变化过大时，从当前种子关节正解位姿向目标插值、减半、重新求 IK（最多八次）。不再直接缩放关节数组，也不再依赖原始解必须落在旧两倍范围内。无效解、持续错误分支或 FK 失败仍停止。
2. 拖拽独立使用 20 mm 前瞻上限、0.10 s 前瞻时间。位置／恒力牵引及普通直线命令仍使用原来的上限，不借用拖拽范围。20 mm 是跟随目标前瞻，不是承诺每个周期实际移动 20 mm。
3. 保留力量到命令速度的线性映射、松手制动及恒力松绳保持／重新拉紧恢复语义。
4. 增加逆解缩短比例、重试次数、FK 验证和接受目标距离的诊断字段。
5. 自适应模式启动时，先用当前关节的 FK 与同一帧实测位姿比较，通过后才发布健康状态。
