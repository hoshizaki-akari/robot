# 2026-10-20 拖拽与启动修复

## 本轮日志证据

0.03 rad 后触发 `fixed-pose session orientation changed`，不是通信中断。

## 实现

- 原生 TRACKING 启动时配置一次固定关节速度/加速度参数；持续目标更新不再反复配置。
- 目标参考按时间推进；换向从实际位置重新建立参考，实际位置超过旧目标时禁止反向追旧目标。
- 拖拽速度饱和由 50 提至 150 mm/s；5.5 N 输入的控制器测试输出为 150 mm/s。
  这是指令速度，不是已测得的真机速度。位置/恒力牵引没有同步放大到此速度。
- 会话姿态容差由 0.03 调至 0.10 rad（约 5.73°）；未修改安装方向标定。
- 保留停止、松手、遥测失效处理；未取消全部约束。

## 启动修复

Windows LocalAppData 文件在用户启动日志中不可见，但在本次诊断进程中存在；
不同启动上下文为何呈现不同结果尚无充分证据。
启动器现优先读取 WSL 用户目录 `.local/share/aubo-traction/connection.clixml`，
找不到时回退至 Windows LocalAppData。配置工具会同时生成共享副本。
共享副本仍是 Windows 当前用户保护的凭据，不在 Git/项目内；目录 700、文件 600。
配置检查失败会明确退出非零；成功启动不再只输出配置 JSON。
