# 松手回退、拖拽线性与恒力负载释放修复

更正：本页“恒力释放后结束任务”的策略已撤销，改回同轮松绳保持、拉紧自动继续。
当前实现以 `CONSTANT_FORCE_RESUME_FIX_20261020.md` 为准；拖拽线性和制动改动保留。

## 本轮证据

输入 `session_1792484871772_full_log.zip`、`session_1792485091096_full_log.zip`。
拖拽低于 0.5 N 的记录中，非零指令已由上轮的大量记录降到本轮约 47/1573 条；
本轮手感问题不再等同于上轮噪声反复触发。
当前保持会把稍早采样的关节角重新作为运动目标；在采样/发送期间仍运动时，
该目标可能落在实际位置后方。这是回退的明确软件机制，物理贡献仍需实测确认。
原拖拽有效增益 0.032 m/s/N，约 5 N 就达到 150 mm/s，故较轻和较重输入都饱和。
恒力末段实际力约 0.5–1 N，任务仍 TRACTION，方向/力控流程可能继续等待或修正；
这不是积分误差持续累积，因为 AUBO 这条力控策略没有积分项。

## 修改

- `brake_on_hold=true`：松手保持改为在有序发送线程调用停止，不发送旧位置目标。
  仍确认新鲜的物理停稳反馈；新施力后重新配置跟随参数再运动。
- 拖拽有效增益改为 0.010 m/s/N，死区 0.35 N；保留 0.65 N 起动迟滞。
  线性区内指令 v=0.010*(|F|-0.35) m/s：5 N=46.5、10 N=96.5、15 N=146.5、
  20 N=196.5 mm/s；20.35 N 以上饱和于 200 mm/s。
  较轻输入不再和较重输入一样顶速；不能同时保持原先 5 N 顶速又让所有更大力线性加速。
- 拖拽/底层指令速度上限 150 -> 200 mm/s；关节跟随参数 0.8 -> 1.0 rad/s、
  2.0 -> 2.5 rad/s²，均在现有实现支持范围内。牵引速度上限仍 20 mm/s。
  这些是指令/参数，不是已测得的实际末端速度；实际速度比例仍需验收。
- 恒力牵引在建立负载后，持续低力 0.25 s 则请求停止并等待实测停稳。
  释放阈值为 min(1.2 N, 目标力*0.25)，避免低目标力被固定阈值误判。
  建载阈值为 max(两倍释放阈值, 目标力*0.4)。初始松绳和短暂低力不直接结束任务。
- 停稳后记录 `CONSTANT_FORCE_LOAD_RELEASED`，回到方向锁定状态。
  再拉紧不会自动恢复；需重新设置目标力并点击开始。网页明确显示此原因。
  没有自动重置力传感器零点，也不把负载下的偏差当作零点去消除。
- 启动器给 manager 同样加载 response_tuning.yaml，保证释放策略真正生效。
