# Run 13-A｜硬件、接口与时序审计（2026-10-10）

## 本线问题
在研究复杂力控前，确认公开接口究竟提供了什么、哪些风险来自版本/接口层，以及哪些信息只能由现场测试确定。

## 核验到的资料
1. **FAIRINO 官方下载中心**：列出 QX 控制软件 V3.9.3（2026-02-11）、Python SDK v2、C++ SDK v2、8083 状态反馈协议、机器人命令协议及 FAIRINO ROS 2 下载项。官方入口：https://www.fairino.com/SERVICE 。下载中心只说明可获取资料，不代表已知现场机器人安装了该版本。
2. **SDK 文档 V3.9.5**：版本记录写明 2026-04-24 增加/更新 CNDE 实时状态反馈配置接口，包括设置状态反馈周期、增删实时状态字段和查询配置。文档入口：https://documentation.fairino.co.in/SDKManual/python_intro.html 。需按现场控制器版本匹配，不能跨版本照抄接口。
3. **ServoCart 调用节奏**：FAIRINO 支持 FAQ 描述 ServoCart/ServoJ 命令可按 1–16 ms 间隔调用（约 60–1000 次/秒）。来源：https://support.fairino.us/portal/en/kb/articles/fairino-faq 。这是命令调用约束，不是 measured plant bandwidth，也不保证外部反馈每次都新鲜。
4. **官方 ROS 2 驱动仓库**：https://github.com/FAIR-INNOVATION/frcobot_ros2 。仓库含版本特定硬件包目录，README 指出需机器人软件版本大于 V3.7.1。必须将 FR5 固件、SDK、硬件插件 tag 对齐。
5. **外置 KWR75 系列 ROS 2 驱动**：https://github.com/ian-chuang/kwr75_force_sensor_ros2 。README 说明目前在 Ubuntu 22.04 + ROS 2 Humble 测试，通过 serial_driver 经串口通信；发送启动命令 `0x48 AA 0D 0A` 使传感器发送 1 kHz 数据。该 1 kHz 是设备/驱动宣称的数据流目标，尚不等于本机实际到达率、无丢包率或控制闭环率。驱动是第三方实现，不是厂商认证的实时性能保证。
6. **用户报告的风险信号（不是确认的厂商缺陷）**：
   - https://github.com/FAIR-INNOVATION/fairino-python-sdk/issues/20 ：Fair5 用户报告 SDK 的 FT_GetForceTorqueOrigin/FT_GetForceTorqueRCS 返回全零，UI 也显示全零，问题仍不能据此判定为普遍故障。
   - https://github.com/FAIR-INNOVATION/fairino-python-sdk/issues/23 ：用户报告控制器 V3.9.6 的 raw F/T 数据字段疑似重复。
   - https://github.com/FAIR-INNOVATION/frcobot_ros2/issues/32 ：用户报告在 V3.9.5 组合下，ServoJ 写入前需要 ServoMoveStart 初始化，否则 ros2_control 硬件 write 可能阻塞。它是可复现风险提示，不能替代现场复现/厂商确认。

## 对项目的决策
- 把“FR5 命令链、外置 KWR75D 数据链、时间基准、停止路径”作为 G0 前置，不先调导纳参数。
- 明确区分外置 KWR75D 与 FR5 自带/集成 F/T API；若实际使用外置 KWR75D，不应把机器人内置 F/T API 当成唯一测力来源，也不可把两条数据流未经坐标/时间核验直接混合。
- 每个样本必须保留采样时间（若设备可给）、主机接收时间、序号/重复帧标记、frame_id、单位、驱动与固件版本。消息到达时间不能冒充真实采样时间。
- “ServoCart 支持高频调用”只能支持进一步台架测试，不得作为实际位置带宽、力跟踪带宽或稳定性证明。

## 最小验证实验
E0 无接触并固定机器人：记录 ROS/主机 monotonic timestamp、命令/实际关节与 TCP 状态、KWR75D 六轴样本序号和接收时刻至少一个完整测试窗口；统计实测频率、中位/尾部间隔、重复帧、丢帧、时延和抖动。
E1 对传感器施加独立参考已知的 ±Fx/±Fy/±Fz 与已知力臂产生的力矩，逐轴验证符号、比例、串扰、零偏和重复性；使用独立测力计/砝码及已知力臂。传感器零点归零不得替代独立真值。
E2 在无接触安全空间发送低幅、小范围、低速阶跃/正弦命令，时间对齐命令和反馈，测 command-to-motion 延迟、抖动、跟踪增益和相位。幅度、频率与停止条件必须根据现场风险分析确定；先确认独立停止链有效。
E0/E1 未通过时禁止接触体模和真人。

## 证据分级
- 官方资料支持：存在 SDK/状态协议/ROS 2 入口及 CNDE 实时状态配置 API。
- 公开第三方实现支持：KWR75 系列可经 ROS 2 串口驱动读取；需复现当前系统。
- 用户报告风险：SDK 返回零值/疑似重复通道、ServoMoveStart 初始化问题；不是已确认的普遍缺陷。
- 本项目待实测：安装版本、端到端延迟与抖动、实际频响、KWR75D 轻载信噪比、停止链独立性。

## 本线输出
G0 必须先完成版本清单、六轴真值校准、数据完整性和停止链；否则所有后续接触估计与控制实验都没有可靠输入。
