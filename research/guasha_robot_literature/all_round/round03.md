# 第3轮：宽刮板的接触位置怎么估、力矩怎么修正法向、未知曲面上怎么恒力

> 学习目标：看懂"机器人怎么知道刮板压在背上的哪一点、有没有压歪、以及怎么在弯弯曲曲的背上保持稳稳的力"。这一轮把"把板当成一个点"的粗糙做法，升级成"已知板形状 + 在线估接触位置 + 用受力歪斜自动摆正板"的聪明做法。

## 1. 这一轮在解决什么问题（为什么重要）

上一轮（run2）点出了一个根本困难：让机器人刮背，难在"既看得见弯曲面，又控得住力"。但那时还停留在"把刮板当成一个笔尖（TCP 点）去压"的思路。

这一轮要补的是具体算法。麻烦在于：真实的刮痧板是有宽度的金属/牛角片，它压在背上是一片接触，而不是一个点。于是三个问题冒出来：

- **接触位置怎么估**：板压在背上，到底受力最重的是哪一点？偏左还是偏右？
- **法向怎么修正**：背是弯的，板怎么自动摆正、顺着曲面"正对着"压下去，而不是斜着戳？
- **未知曲面上怎么恒力**：没有精确的人体 3D 模型，机器人在起伏的软背上怎么保持力度不变、还不出事？

这一轮最重要的新判断是：**刮板不能只建模为一个点，而应建模为"已知板形状 + 在线估等效接触位置/接触线 + 局部接触坐标系"**；而且腕部那颗六维力觉传感器测到的"力矩（歪劲）"，不是附属信号，而是判断"板压在哪、偏没偏"的核心线索。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

- **等效接触位置与偏载（e_edge）**
  - 一句话定义：宽板压在背上是一片受力，但我们可以用"合力作用点"等效成一个点（压力中心），并看它偏到哪一边。
  - 生活比喻：一群人推一扇门，合力效果等价于"某一个人用总力推在门上一点"；如果这点偏到门轴附近，门就推不动——偏载就是"受力偏心"。
  - 在刮痧里：刮板压歪了，实际最重力的点会偏左或偏右，e_edge 就是量化这个"偏心程度"的量，用来提醒机器人"你板歪了"。

- **力矩纠正姿态（ω = T_c × z 这一招）**
  - 一句话定义：当板没有正对曲面时，接触摩擦会产生一个"拧劲"（力矩 T_c），用它与板自身中轴 z 算个叉乘，就得到板该往哪边转才能重新对准。
  - 生活比喻：你用手掌斜着推墙，会觉得手被扭了一下；这个"被扭的感觉"其实告诉你"手该转正一点"。
  - 在刮痧里：机器人不用先知道背长什么样，靠受力歪斜就能自己把板摆正，相当于"力觉当成了找正传感器"。

- **多率融合（视觉慢、力觉快）**
  - 一句话定义：两种传感器频率不同，不要强行同步成同一个节拍，而是各管各的、互相补充。
  - 生活比喻：你边走边用眼睛看前方的路（几秒扫一眼），同时脚底时刻感觉地面高低（每步都有）——两者频率不同，但合起来你既不会撞墙也不会崴脚。
  - 在刮痧里：相机看前方曲面只要 15–30 Hz 就够；力觉要尽可能高频，两者错位互补。

- **重力 / 零偏标定（别只按一次归零）**
  - 一句话定义：力传感器装机后，要测出"板自身重量、重心、安装歪斜、零点漂移"带来的假信号，并扣除。
  - 生活比喻：电子秤要先"去皮"——放上一个空盘子再归零，否则盘子重量会被当成你压上去的力。
  - 在刮痧里：板一换姿势，它自身重力就会在力矩上产生假信号；不标定，机器人会把"板太重"误判成"压偏了"。

- **加加速度限制（jerk limiter）**
  - 一句话定义：给机器人的"猛地一抖"设上限，让速度变化平滑，避免刚性接触时弹跳。
  - 生活比喻：电梯如果瞬间加速会吓人一跳；好的电梯是缓缓提速。jerk limiter 就是给机器人加"缓启缓停"。
  - 在刮痧里：板贴着皮肤时突然一顿一冲会刮伤人或抖出噪声，所以要限住这个"抖"。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 家族一：把"板当成一个点"升级成"已知几何 + 在线估接触位置"

这一家族回答"板压在哪、偏没偏"。经典理论（Bicchi 等 1993）早就证明：只靠内部的力/力矩测量，就能反推出接触位置、接触力和法向力矩——这叫"内在接触感知"，正是我们把力觉当触觉的理论源头。

关键数学关系就一句：**τ = r × f**（τ 读"涛"，是力矩；r 是"从传感器到接触点的力臂"；f 是力；叉乘表示"力偏离中心多远、造成多大拧劲"）。但光有力矩只能确定一条"力的作用线"，还得用**已知的板形状**去和这条线求唯一交点，才算真正定位接触点。Bota 公司的力觉工具库就是把"六维力觉 + 已知板面 → 接触点"做成现成模块，这正是我们该给刮痧板抄的第一个接触估计器。

Kutsuzawa 等 2026（IJRR）更进一步：用粒子滤波把"接触位置"当成一个随时间变化的隐藏状态，连同工具形状一起估。但我们的板形状是已知的，所以问题被大幅简化成：**已知板几何 + 六维力觉 → 等效接触位置 p_c、偏载 e_edge、接触坐标系**。第一版甚至不必上复杂的粒子滤波，先做解析几何 + EKF/UKF（见术语表滤波器）就够，后续再比 PF。聪明之处在于：别把单帧 τ = r × f 的反解当成真理，而要用历史力 + 运动 + 几何"持续猜"，像雾里看人、把多帧糊照片拼出真实位置。

### 3.2 家族二：用接触力矩把板摆正、贴上曲面（法向—姿态—恒力同步）

这是和刮痧**最像**的一族。Li 等 2023（TMECH）研究"未知模型工件抛光"：没有精确曲面图，就靠接触受力实时判断"板当前姿态"和"真实表面法向"差了多少，再把一条简单的二维预画路径在线扭成真实的三维曲面路径，同时保持法向恒力。

它最值得抄的关系是：**ω = T_c × z**（ω 是让板转动的趋势方向；T_c 是接触拧劲；z 是板自己的中轴；叉乘算出"板该往哪边拧才能重新对准曲面"），每个控制周期积成一点姿态修正 ΔR。板一旦摆正，切向力 F_x、F_y 趋于 0，法向力 F_n ≈ F_z，再跟踪目标力即可。实验在多种未知曲面上做到平均法向误差约 1.3°、力误差约 ±1 N——几乎可直接当我们的 baseline。区别是：人家有 1.3 kHz 的微型主动柔顺机构，我们没有，得靠 FR5 位置伺服 + 外环导纳；而且人体是软、会动、摩擦大的，不能把全部力矩都当成"姿态歪了"（τ = τ姿态 + τ摩擦 + τ形变）。

Li 等 2025（JMP）补了一个关键提醒：如果每帧都把视觉算出的法向直接当姿态命令，法向噪声会变成姿态抖动，抖动又改变接触深度，二次污染力度。所以必须**法向滤波 → 四元数平滑 → 角速度限制 → 才生成目标姿态**。他们还把"变阻抗"参数设计成带约束的二次规划（QP），软硬随情况调。

Dong 等 2026 把"力 / 位置 / 姿态"三者沿曲面同步变化，提出统一的任务样本 q_i = { 弧长 s_i、位置 p_i、时刻 t_i、法向 n_i、姿态 R_i、目标力 F_d,i、目标速度 v_d,i、状态 state_i }。这对我们极有用：前刮恒力、转向降速、轻力回程，本质上都是沿"走了多远"的同步插值，而不是"轨迹点 + 另一条独立的力线程"硬拼。

### 3.3 家族三：视觉和力觉怎么分工（遮挡下互补）

Eye-in-Hand（手眼相机）最大的尴尬是：刮板正好挡住真正接触的那块皮肤，相机根本看不到接触点。Bimbo 等 2022（RA-L）证明：当视觉被遮挡时，直接用末端的力/力矩去推断可能的接触位置，还能顺带重构环境几何——"接触本身就是一种几何传感器"。

这给了我们一个比"相机必须始终看到接触点"更合理的架构：**相机（D435）看前方 → 提供前视曲面几何；板到位后 → 六维力觉负责接触后验修正**。两者在空间上错位、在时间上多率，是互补而非要求同一时刻看同一点。

### 3.4 家族四：低频也能干活——可部署的导纳与安全

这一族专治"实机落地"。Cui 等 2026（婴儿髋关节超声）给出完整可抄的上线流程：多姿态重力/重心/零偏标定 → 基于力矩的姿态控制 → 模糊神经网络变导纳。它明确警告：只做一次空载归零不够，必须多姿态标定，否则板一换姿势，自身重力矩就被误当成皮肤接触力矩，污染接触点估计。

同一团队 2026 年 8 月的 DDH 超声论文更是颗"定心丸"：六维力觉 100 Hz、导纳外环只跑 50 Hz，参数 M=0.25 kg、K=1250 N/m、B=25 N·s/m，目标 -2 N 力，实测 -2.045 ± 0.213 N。这证明**50–100 Hz 外环不等于软组织恒力任务做不了**——关键是速度、滤波、虚拟参数、延迟、安全阈值一起设计。他们还设了 6 N 超限暂停/回撤、10 N 终止回安全位，我们的状态机从第一版就该有这种独立安全监督。

Mae 与 Kikuuwe 2024 针对"位置控制机器人有死区延迟"的问题，在导纳输出端加严格离散设计的加加速度限制（从微分包含 + 隐式欧拉推得），实测 UR3e 约 6 ms 死区下抑制了刚性接触振荡。这提醒我们：FR5 的真实延迟和抖动要实测，不能只看 SDK 宣称的频率。工程上 ROS 2 的 adaptive_admittance_controller 已把力觉去偏、重力补偿、低通、柔顺坐标系、在线改 M/D/K、以及"开环模式避免硬件延迟被重新注入命令环"都做好了，可直接研究复用。

## 4. 关键算法/公式的直觉（大白话）

- **τ = r × f**：板压歪了、一边重一边轻，就会在腕部产生"拧劲"。力偏离中心越远（r 越大），拧劲（τ）越大。就像推门，离铰链越远越省劲——这里反过来，拧劲的大小泄露了"力作用在哪"。
- **ω = T_c × z**：板没正对曲面时，摩擦产生拧劲 T_c；用它和板中轴 z 一叉乘，就得到一个"该往哪边转正"的指向。相当于板自己"感觉"到歪了，自动算出修正方向。
- **p_c、e_edge**：把所有分布压力等效成一个点 p_c（压最实的那点），e_edge 衡量它偏到板左边还是右边——偏了就说明板歪了，要纠。
- **法向滤波 → 四元数平滑 → 角速度限制 → R_d**：视觉算出的"正对方向"像手抖拍照会糊，不能直接用，要先稳一稳、平滑转、限速，才变成板真正该摆的姿态。
- **M/K/B 虚拟参数**：导纳把"力误差"换算成"该往法向多压/少压多少"，M（惯性）、K（弹簧硬度）、B（阻尼）就是那块"会下陷软垫"的三个性格，一起决定压下去多顺、多稳。

## 5. 仍然没解决的坑 / 局限（2–4 条）

1. **软组织把力矩"搅浑"了**：人体是软的、会随呼吸起伏、摩擦大，力矩里混着"姿态歪了 + 皮肤摩擦 + 被压陷形变"三种成分，刮痧时不能像刚性工件那样把全部力矩都当成姿态误差，需要靠运动方向、视觉法向和时序去分离——这招目前还没验证。
2. **宽板从"点接触"到"线/面接触"的可观测性未知**：六维力觉对点接触算得清，但刮痧板是有限宽的一片接触，能不能稳稳反推出"等效那一点偏左还是偏右"、偏差有多大，还要实测验 KWR75D 的力矩分辨率。
3. **FR5 真实带宽没测**：50–100 Hz 外环"理论上可行"，但 FR5 的位置命令/反馈到底多延迟、多抖、稳定更新率多少，得先上机测清，否则导纳参数设了也白设。
4. **前刮/回程的安全力—速范围待定**：多大目标力配多快速度既有效又不伤人，需要实机标定，不能纸上谈兵。

## 6. 这一轮你该记住的 3 件事

1. **刮板不是点，是"已知形状 + 在线估接触位置"**：用 τ = r × f 配合板几何，就能从力觉反推出压在哪、偏没偏，这是把力觉当触觉的核心。
2. **力矩能当"找正传感器"**：板歪了产生的拧劲 T_c，经 ω = T_c × z 就能算出该往哪转摆正——这是未知曲面上恒力的关键一招（Li 2023 可直接当 baseline）。
3. **低频 + 好好标定 + 安全闸，就能干活**：50 Hz 外环已被医疗软接触任务验证可行；上线前必须做多姿态重力/零偏标定，并从第一版就加 6 N/10 N 这类硬安全阈值。

## 7. 和前后轮的关系

- **承接：run2 留下什么，这轮接上。** run2 提出"感知曲面 + 控力"两大难，并把板当成一个 TCP 点。这一轮接上具体算法：把"点"升级为"已知几何 + 在线估接触位置/线 + 局部接触坐标系"，并用接触力矩去修正法向与姿态，补上了 run2 缺失的实现路径。
- **铺垫：为 run4 埋了什么伏笔。** 本轮明确把问题从"点接触"推进到"等效接触位置/压力中心/分布接触"——这正是 run4 要专门追的"宽刮板从点接触扩展到线/面接触的可观测性"。同时埋下了 FR5 外环导纳的"离散稳定域、能量池、延迟裕度"以及单 D435 前视曲面建模两条线，为后续低频导纳部署和 Eye-in-Hand 前视建模铺路；并再次确认 RL 后置，等接触状态、基础柔顺和实机带宽测清再说。
