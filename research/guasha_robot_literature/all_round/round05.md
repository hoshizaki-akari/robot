# 第5轮：滑动接触里的摩擦干扰、软组织刚度在线辨识、刚-软异质接触的估算法

> 学习目标：看懂"机器人刮痧时，板在背上滑动带来的摩擦会怎样骗过力度感知，以及怎么用算法一边刮一边猜出皮肤的软硬和真实按压方向"。读完应能向一个完全外行的人解释：为什么不能简单把测到的力方向当成板该压的方向，以及我们打算分几步、由易到难地把"摩擦、软硬、接触位置"都估出来。

## 1. 这一轮在解决什么问题（为什么重要）

前面几轮我们基本理清了一件事：机器人靠"眼睛"（RGB-D 相机，就是那种既拍颜色又量距离、能算出背是弯是平的设备，详见术语表）看曲面，靠"触觉"（6D 力/力矩传感器，能称出压了多重、往哪边歪，详见术语表）估法向（法向 = 垂直皮肤表面的方向，像贴在墙上的图钉钉尖指向墙外那条线）。

但 run4 之后留下一个很现实、也很容易被忽略的难题：**刮痧不是"垂直轻轻按一下"，而是板贴着皮肤持续滑动地刮。** 这一"滑动"就出大事了——只要板在动，皮肤表面就有摩擦，摩擦力是沿着皮肤、贴着表面走的（这叫"切向力"），它和"垂直压下去的力"混在一起，被 6D 传感器一块测到了。

麻烦在哪？如果我们偷懒，把"测到的合力方向"直接当成"该垂直压下去的方向"，那摩擦力就会被误认成"板歪了"，算法就会错误地纠正板的角度。粗略算一下：摩擦系数 μ=0.3 时，这个错误角度已经有约 16.7°——对刮痧来说，板歪 16° 很可能就刮伤皮肤或刮不到位。所以"力方向=法向"这个简单想法，在刮痧里**原则上就不成立**。

这一轮要解决的，就是三件事：①滑动摩擦怎么从力里分出来、别污染法向；②背部软组织会塌陷、软硬不一，怎么在线（一边刮一边）估出局部"软硬"；③当接触面一边是硬板、一边是软肉（"刚-软异质"）时，怎么把几何、软硬、力一起估准。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

- **摩擦偏置（friction bias）**：滑动时测到的力里混进了擦过去的摩擦力，让"合力方向"歪掉的那部分系统性误差。
  - 生活比喻：你闭眼推一个在桌面上滑动的盒子，感觉到的"推力方向"其实是"往下按的劲 + 往前推的劲"的合方向，并不等于你真正想让它前进的方向。
  - 在刮痧里：板在背上刮，测到的力 = 垂直按的力 + 滑动摩擦的力，直接拿来当法向会算歪。

- **接触刚度 K_e（contact stiffness）**：皮肤被压下去一点、会产生多大回弹力的"软硬程度"，数值大=硬，小=软。
  - 生活比喻：按床垫（软，K_e 小）和按木板（硬，K_e 大），同样按下去 1 厘米，木板顶你的劲大得多。
  - 在刮痧里：背不同位置、人紧张或放松时，局部软硬会变，机器人若能估出 K_e，就知道"压这么多该出多大反弹力"。

- **可观测性（observability）**：理论上，从我们手头的传感器数据，到底能不能唯一反推出某个隐藏量。
  - 生活比喻：只听脚步声猜一个人手里拿没拿东西——有些信息根本听不出来，就叫"不可观测"。
  - 在刮痧里：比如板停下不滑时，靠"运动方向"去分摩擦就失效了（不可观测），这时得换别的线索。

- **刚-软异质接触（rigid–soft heterogeneous contact）**：一边是硬邦邦的工具（刮痧板），另一边是会塌陷的软体（人体组织）的贴合接触。
  - 生活比喻：用铁勺背去压一团发面，勺是硬的、面是软的，两者接触时的力学很不一样。
  - 在刮痧里：板硬、背软，所以压下去背会陷，不能当"压在硬墙上"来算。

- **消融实验（ablation study）**：做算法时，每次只加一个新功能、看看它单独贡献多少，像"把一道菜的某味调料先去掉尝尝"。
  - 生活比喻：做蛋糕先不放泡打粉看塌不塌，再放回去对比，就知道泡打粉管什么用。
  - 在刮痧里：我们打算一层层加"法向修正→接触位置→摩擦→软硬"，每层单独验证效果。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 方法家族一：摩擦感知的法向估计（不把切向摩擦当噪声）

**它在干什么**：本轮最重要的论文是 Nasiri & Wang（UR 2024，已实机验证）。它的聪明之处在于——不再假装"摩擦力不存在"，而是主动利用"机器人的运动命令"：既然板是我们在命令它往某方向滑的，那滑动方向（速度命令）我们是知道的。论文就把"测到的力"拆成两部分：垂直皮肤的那份（法向力 F_n）和贴着皮肤滑动的那份（切向力 F_t），并用运动方向去猜/补偿摩擦，从而把真正的法向算准。它还把估出的法向放进"力-运动混合控制框架"，ROS2 + 7 自由度臂 + 末端力传感器上都跑通了，工程门槛低。

**为什么聪明**：它承认刮痧一定有摩擦，并把"摩擦系数 μ"当成一个要在线估计的状态，而不是当错误消掉。Huang 等（2023）给了另一条路：先在已知平面上用数据学出"力→法向"的映射（局部加权回归，类似"照着样例找规律"），再到未知曲面用，并用"迭代学习控制"专门压低摩擦带来的方向误差。于是我们现在有三条漂亮的法向估计基线可以比较：①视觉（相机算）②力+速度（摩擦感知）③学习型映射，最后再比"视觉+力融合"——这比只说"融合后好一点"更有说服力。

**我们能抄什么**：第一版把法向估计从"法向 = 力方向"升级成"法向 = 视觉先验 + 力分解 + 摩擦补偿"；第二版再上卡尔曼滤波器（一种"边测边估、滤掉噪声"的递推算法，见术语表）估摩擦系数。注意：制造任务是硬工件，人体背会塌陷，所以 Nasiri 法只能当 baseline，不是终点。

### 3.2 方法家族二：软组织刚度在线辨识（Hunt–Crossley + 卡尔曼族滤波）

**它在干什么**：Zhu 等（2025）把"Hunt–Crossley 非线性接触模型"和"迭代卡尔曼滤波（IKF）"结合，去辨识生物组织的参数。关键公式直觉是：垂直力 F_n = K·δ^m + C·δ^m·δ̇，其中 δ 是压陷深度、δ̇ 是压陷速度、K 是弹性硬度、C 是"和速度有关的耗散（像黏滞阻尼）"。它把"弹性"和"速度相关的损耗"分开，比普通线性方法更能描述强非线性软组织。

**为什么聪明**：假如机器人看到"板往里陷了 3 毫米"，它不会默认这永远代表同一种东西——可能是这里肉软（K 小），也可能是板压得猛（速度大）。分清楚这俩，机器人就不会把"软"误判成"压得轻"。另一篇 Zhu 等（2025，EKF+最大似然）作为更轻量、更好实现的软组织辨识 baseline，供 IKF 太复杂时替换。

**我们能抄什么**：这一层需要可靠的"压陷深度"输入，所以**必须等几何/视觉层成熟后再上**，别一上来就做。

### 3.3 方法家族三：刚-软异质接触的 EKF+MPC 估计

**它在干什么**：Zheng 等（2025）把"接触几何 + 接触刚度 + 法向/摩擦力"全当在线估计对象，用 EKF（扩展卡尔曼滤波）估参数、用 Hertz 接触模型（描述两个物体压在一起时接触区力学）分解/预测力，再放进 MPC（模型预测控制，见术语表：每步走前先想后几招选最优）做"力-位置协调优化"。实验跨木材/泡沫/硅胶/海绵，还在人前臂做了"肌肉松弛↔收缩"触诊，能在线反映组织软硬变化。论文报告：相较基线，最大冲击力降约 50%、平均力误差降约 42%。

**为什么聪明**：它把"背是软的、板是硬的"这件事真正建模进去，而不是假装环境是刚体。这正好对应"人体背不是固定刚度环境"。

**我们能抄什么**：后期把估计状态从 [法向, 接触位置] 扩展为 [法向, 接触位置, 摩擦系数, 软硬 K_e]。但这套 EKF+MPC+接触模型比普通导纳复杂，建议作第二阶段算法。

### 3.4 一条串起来的主线：接触状态相关的融合权重

把上面三家族收口，关键思想来自 Lloyd & Lepora（2024）：**别把切向摩擦当要消除的麻烦，把它当刮痧接触状态的一部分**（毕竟刮痧本来就要摩擦）。于是整套接触状态可写成：姿态修正角、接触位置、摩擦系数、软硬。

更重要的是融合权重不该固定。过去可能写"法向 = 0.5×视觉 + 0.5×力觉"。但转向时板停下（速度→0），靠运动方向分摩擦就失效了（不可观测），该降低力觉权重；轻力回程时压得轻，力传感器信噪比低，该提高视觉权重。所以更合理的是：法向 = w_v×视觉 + w_f×力觉，且 w_f 随"垂直力大小、滑动速度、信噪比、当前状态机阶段"动态变。这很可能成为我们第一篇论文里一项自然的算法贡献——**接触状态相关的多速率视觉-力觉法向融合**。

## 4. 关键算法/公式的直觉（大白话）

- **合力 = 垂直力 + 切向摩擦（f = F_n·n + F_t）**：就像你斜着推一个会滑的箱子，推的劲里既有"往下按"也有"往前推"，别把总方向当"往下按"的方向。
- **错误偏角 ≈ arctan(μ)**：摩擦系数越大，把合力当法向错得越离谱；μ=0.3 就歪约 16.7°，足够坏事。
- **F_n = K·δ^m + C·δ^m·δ̇**：压下去的回弹力 = 弹性部分 + 跟速度有关的黏滞损耗；分两半，才能区分"肉软"和"压得猛"。
- **逐层加状态 [姿态修正] → [+接触位置] → [+摩擦] → [+软硬]**：像搭积木，每层加完做消融实验，确认每一块都真有用，而不是一次性堆四个黑箱。
- **法向 = w_v·n_v + w_f·n_f，权重随状态变**：就像开车，晴天多看路（视觉）、雾天多信雷达（力觉），不是永远各信一半。

## 5. 仍然没解决的坑 / 局限（2–4 条）

1. **轻力回程时力传感器信噪比够不够**：KWR75D（腕部 6D 传感器）在回程低压时，力矩信号可能太弱，做接触位置/姿态修正到底行不行，得实机测。
2. **背部摩擦 ≠ 单纯库仑摩擦**：人体背部滑动时的切向力，混合了"表面摩擦"和"软组织被推着剪切变形"，能不能用简单 μ 一个参数压住，仍是假设，未验证。
3. **相机"看前一点"和真正接触点有时空差**：D435 看的是前方未接触处，人体呼吸/局部变形会让预测的法向和真接触点差多少，未知。
4. **FR5 底层延迟/抖动**：外环导纳（把力误差变位置指令的柔顺控制，见术语表）受机械臂网络/伺服延迟卡着，真实可稳定参数域要单独测，论文方法再好也可能被硬件拖后腿。

## 6. 这一轮你该记住的 3 件事

1. **刮痧必滑动，所以"力方向=法向"是错的**；必须用"力 + 运动速度"把摩擦分出来再估法向（Nasiri 2024 已实机验证）。
2. **背部是会塌陷、软硬不一的软体**，不能当硬墙算；用 Hunt–Crossley / EKF 族可在线估"局部软硬 K_e"，但要等几何层成熟再上。
3. **融合权重别写死**：刮、停、回程三阶段该信视觉还是力觉要动态切换，这是很自然的一项论文贡献点。

## 7. 和前后轮的关系

- **承接**：run4 弄清了"面接触（宽刮板压在背上是一片，不是一点）能观测/不能观测什么"——尤其 6D 力矩只能稳稳反推"等效接触位置（压力中心 CoP）"，不能还原整片分布。本轮就接上这个硬限制，去解决真人背部上"滑动摩擦污染力矩 + 软组织塌陷"怎么在线分辨。
- **铺垫**：为 run6 埋下明确路线——①直接在人体背部做"同构 baseline"（参考抛光/超声探头等贴曲面恒力任务，见术语表）；②动态减速（转向/回程时降速保观测）；③力误差补偿（尤其摩擦偏置与轻力段）；④有界变阻抗（bounded variable impedance，软硬随接触状态在线、但有上限地调）。四件事本轮都已指了出处与分阶段做法。
