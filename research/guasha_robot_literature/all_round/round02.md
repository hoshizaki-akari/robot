# 第2轮：刮痧机器人方向的开篇——先搞清楚"要让机器人刮背，到底难在哪"

> 学习目标：读完这轮，你能用自己的话说出"机器人刮背"这条技术链路由哪几段拼成（看见背→画线→知道往哪压→稳稳刮），并且能讲清楚为什么最大的难点不是"再发明一个控制器"，而是把"曲面几何 + 接触力学 + 刮板工具特性"这几件事拧到一起。

## 1. 这一轮在解决什么问题（为什么重要）

假设你要把"刮痧"这件本来靠老师傅手感的事，交给一台机械臂来做。第一反应可能是：这得有多难啊，是不是得先训练一个 AI 学会"怎么刮"？

这一轮做的事，恰恰是先给这个"难"降温。我们没有急着上人工智能（强化学习），而是先去翻了翻别人已经发表的论文，想搞清楚两件事：

第一，**这条路上已经有哪些"别人铺好的砖"**——也就是说，哪些环节已经有正式论文证明能跑通了；
第二，**剩下的、真正没人解决的空档在哪**——也就是我们这篇论文该往哪儿发力。

结论很关键：**第一版系统完全做得出来，而且不用先碰强化学习**。相邻领域（按摩机器人、超声探头贴合、背部三维重建）的人，已经分别把每一段都验证过了。我们真正缺的，不是"再找一个恒力控制器"，而是把"刮板接触"这个特殊问题，作为主线把各段串成一个整体。这一轮就是给整个项目"画地图"，先知道路在哪儿、坑在哪儿。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

本论新出现、又绕不开的几个概念：

- **Eye-in-Hand（手眼相机）**：把相机装在机械臂的"手"上，手伸到哪儿相机看到哪儿。比喻：把眼睛长在手上。在刮痧里：我们用一台 RealSense 相机装在 FR5 机械臂手腕附近，专门贴近看背部曲面；好处是看得清，坏处是刮板会挡住真正接触的那一小块皮肤（这叫"遮挡"）。

- **人工标线 → 3D 轨迹**：人在背上用笔画好要刮的路线，机器人用相机把这条线变成三维路径去走。比喻：你先在背上用笔画好道，机器人照着道走。在刮痧里：这是人和机器人配合的起点，避免机器人自己乱规划路线。

- **法向（Normal）**：垂直于某个表面的方向，也就是"正对着表面、直直戳出去"的那条线（详见术语表）。在刮痧里：刮板必须顺着背部曲面的法向压下去才稳、才不刮伤；法向估错了，板就斜着戳皮肤。

- **恒力控制 / 导纳控制**：恒力＝不管曲面怎么起伏，工具都用稳稳的力压在表面；导纳＝把"力误差"换算成"该往法向多压/少压多少"，像踩在会下陷的软垫上，越用力踩脚越往下走（详见术语表）。在刮痧里：刮痧要力度恒定，太轻没用、太重伤人，所以这是核心指标。

- **RANSAC（随机采样一致性）**：一种从带噪点云里"反复随机抽几个点试模型、保留最一致那次"的鲁棒拟合法。比喻：像在混了石子的沙堆里反复抓几把，找出哪一把最像一块平板。在刮痧里：当背部的皮肤反光、汗毛噪点干扰点云时，用它比单纯 PCA 更稳地估法向。

- **状态机（State Machine）**：把任务拆成几个"状态"按条件切换，同一时刻只在一个状态（详见术语表）。在刮痧里：刮痧分成"前刮（用力）"和"轻力回程（收力返回）"等状态，各用不同力度。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 第一个好消息：有人已经把"画线→三维轨迹"做出来了

我们找到了一篇 2024 年的按摩机器人论文（Xu 等人），它的流程几乎就是我们想要的：

操作者在彩色图像上用笔画一条线 → 相机读出每个像素点的深度（离相机多远）→ 把"图像里的点 + 深度"反投影成空间里的三维点 → 用 B-spline（一根有弹性的软尺按几个图钉弯出顺滑的弧，详见术语表）连成平滑曲线 → 机器人照着刮。

它甚至测过精度：整体误差大概 4.3 毫米（去掉两个明显的异常点后约 2.8 毫米），按摩时目标力设为 6 牛顿（牛顿是力的单位，大约相当于 600 克重物的重量感）。

**它聪明在哪**：用"人画线"这种最直觉的方式指定轨迹，比让机器人自己规划友好太多。**我们能抄什么**：整套"2D画线→3D轨迹"的算法，可以直接当第一版基线。

但它留了一堆空给我们补：它不是真正的 Eye-in-Hand；没有腕部六维力传感器；力控只压在固定的"垂直方向"，没有顺着背部曲面变化；没处理刮板边缘；没有"前刮用力、回程收力"。所以——别人没把我们的课题做完，但给了我们一个很好的起点。

### 3.2 第二个好消息：背部三维重建也有高度同构的研究

西南交通大学一篇 2024 年硕士论文（程丽红），硬件几乎和我们一样：CR5 机械臂 + 装在末端的 D435 相机。它的做法是：机械臂带着相机多角度扫描背部 → 生成彩色点云（带距离的照片堆）→ 去噪 → 利用机械臂自己知道的"手在哪"给点云对齐一个初值 → 再用 Colored ICP（把两堆点云反复挪到最重合，详见术语表）拼成完整背部曲面 → 局部拟合出法向和机器人该摆的姿势。

**它能直接抄的**：把"穴位识别"整块删掉，只复现"机械臂位姿 + Eye-in-Hand + 彩色 ICP + 背部曲面 + 法向"这一段，就解决了我们第一个核心难点。

### 3.3 刮板要"正对着皮肤"：每个轨迹点都得有自己的局部坐标系

光有轨迹还不够。刮板走到某一点，得知道"皮肤朝哪鼓"，也就是这一点附近的法向 n。做法像这样：取这一点周围一小撮邻居点，用 PCA（主成分分析，简单说就是找这团点最"扁"的方向）算出法向；轨迹本身的走向给出"切向"t（沿皮肤滑动的方向）；再用叉乘得到第三个方向 b。三个方向拼成一个局部坐标系 [t, b, n]，再叠加刮板工艺要求的倾斜角，刮板就知道该怎么摆了。

**为什么聪明**：不再是"整个背用一个方向"，而是"背上的每个位置都有自己的正前方"。这正是曲面刮痧和平面按摩的分水岭。

### 3.4 刮的时候力度要稳：恒力与导纳

沿切向 t 继续走规划好的路线，沿法向 n 做导纳控制维持接触力。第一版用最朴素的导纳：力误差（实际力减目标力）被当成"该往法向多压/少压多少"的位移修正。升级版可以抄 Jiang 等人 2024 年的"积分自适应导纳"——它在线估计软组织有多软多硬，自动修正参数，比固定参数更稳。

### 3.5 视觉估错法向怎么办：用力的反馈来修正

单台相机在刮板遮挡下，法向可能估偏。这一轮找到一篇特别对症的论文（Iturrate 等人 2025）：它研究的就是"不知道表面法向，机器人还怎么沿未知表面走"。办法是：用接触过程中的运动和力信息，在线把法向重新估一遍，再让导纳方向跟着修正。

我们的落地思路：D435 估的法向当"先验"，接触后让"力/运动驱动的自适应法向"当校正项，两者融合。这比单纯靠相机 PCA 估法向更有研究价值。

假如你是调试工程师：第一天带刮板上机，你发现刮板刚压上背，D435 估的法向就偏了十几度，板子斜着戳皮肤。你不用慌着重训视觉模型，而是看力传感器——若"偏左"那侧力矩明显更大，就知道法向估偏了方向；于是让程序在接触后用"力/运动自适应法向"把角度慢慢掰回，刮板重新正对皮肤。力反馈在这里就是你的"第二双眼睛"。

### 3.6 前刮用力、回程收力：先做状态机，别急着上 RL

刮痧不是一直用猛劲。合理的流程是：靠近→触碰→缓缓加力→前刮（用力 F_scrape）→转弯→轻力回程（收力 F_return）→重复。转弯处必须平滑减速、平滑切换目标力，否则角点上会"咯噔"一下冲击皮肤。

**重点**：状态机就能搞定这件事，第一阶段完全不需要强化学习。至于"医学上某处到底该刮多少牛"，那是医学参数，不是机器人该在第一篇论文里回答的。

## 4. 关键算法/公式的直觉（大白话）

挑一个最核心的思路讲透：**"力误差怎么变成位置修正"（导纳的直觉）**。

公式是 `M·加速度 + D·速度 + K·位置偏移 = 实际法向力 − 目标力`。别被符号吓到，它的意思是：机器人算出一个"偏移量 Δx"，把它加到原本规划的路径上，让刮板沿法向多压一点或少压一点。当实际力比目标小（压轻了），这个公式就给出"再往皮肤方向多走一点"的指令；压重了就往回退一点。整台硬邦邦的机械臂，因此表现得像一根会自己找平衡的弹簧——这正是一开始说的"柔顺控制"。

再打个比方：**导纳控制像空调恒温器**。设 25℃（目标力），实测 23℃（实际力小），温差（力误差）就命令加热（沿法向多压）；到 27℃（压重了）就反向少加热。机器人不靠硬顶，靠"误差→微调"贴到目标，皮肤不会被猛地顶一下。

另一个直觉：**"用六维力反推刮板歪没歪"**。刮板如果是宽宽的、压在背上是一片接触，力传感器能测到 6 个数（三个方向的力 + 三个方向的拧劲）。如果板压歪了、一边重一边轻，力矩（拧劲）就会暴露"偏左还是偏右"。所以 6D 力不只是称重量，更是判断"板正贴没贴"的探针。

## 5. 仍然没解决的坑 / 局限

- **单相机遮挡下的法向稳定性未知**：别人用双相机解决遮挡，我们只有一台 D435，刮板又正好挡住接触区，单相机到底稳不稳，得自己验证。
- **宽刮板的接触位置怎么标定**：板有宽度，不能只当成一个点（TCP）。板实际接触边缘/接触线在哪、力矩能不能精确辅助标定，这一轮还没答案，被列为下一轮第一优先。
- **低频导纳在真实机械臂上的稳定性**：FR5 是"位置控制"型机器人（只能听"移到这儿"，不能直接听"用多大劲"），网络还有延迟，导纳外环频率被卡住，离散稳定性要在实机上验证，不是纸上谈兵。
- **局部软组织形变 / 部分滑动**：ICP 只能处理整体平移旋转，压陷造成的局部变形、板一半粘一半滑的"部分滑动"，靠腕部 6D 合力结构上有观测限制，估不清细节。

## 6. 这一轮你该记住的 3 件事

1. 第一版系统**不用先上强化学习**——相邻领域已分别验证每段的可用性，先把"几何 + 力 + 刮板"串成基线。
2. 两个现成基线可直接抄：Xu 2024（画线→3D轨迹）和程丽红 2024（D435 Eye-in-Hand 背部重建），它们是第一版骨架。
3. 真正的创新空档在"曲面几何 + 接触力学 + 刮板工具特性"的结合，尤其是**宽刮板接触位置估计、6D 力矩修正法向、未知曲面恒力、低频导纳落地**这四点。

## 7. 和前后轮的关系

- 承接：无（开篇）。这是项目最早一轮，没有前身，先画全局地图。
