# 第10轮：动态机器人超声强基线 + 运动环相位滞后瓶颈 + 软体双层形变表示 + 频域力跟踪下一步

> 学习目标：本轮帮你认清一件事——刮痧机器人"刮不稳"可能不是软件算法没调好，而是机械臂本身的运动环在拖后腿；同时给你两套更聪明的"背部表示"和"末端恒力"思路，并指出下一步该拿真机做频域体检。

## 1. 这一轮在解决什么问题（为什么重要）

上一轮（run9）我们定好了"参照人体按摩来定基线 + 安全兜底层"。这一轮要追问一个更尖锐的问题：**我们一直当成主力的"导纳外环恒力"算法，到底够不够？还是说，机械臂底层的运动环本身就是个硬瓶颈？**

打个比方：你让一个学徒按固定力道给你按摩，他手法（算法）学得挺好，但他本人反应慢半拍（运动环延迟）。这时候无论你多仔细地教他"用力公式"，他也总是慢一拍、按过头。本轮发现：在动态软组织（比如人呼吸时背部一上一下）场景下，**慢半拍这个毛病，可能不是调算法能根治的**。

更重要的是，本轮搬来了两个重量级参照：一篇 2026 年 IJRR 的"机器人超声"论文给出了"直接力控制"对比"导纳"的强证据；另一篇 IJRR 提出了软体"标准几何 + 实时形变"的双层表示。这两样都能直接抄进刮痧链路。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

- **相位滞后（phase lag）**：一句话定义——你下指令和机器人真正执行之间，不但有"时间差"，还表现为"方向相反"的错位。生活比喻：你喊"起跳！"，朋友过了半秒才跳，而且你喊起他正好在下蹲——这就是相位滞后。在刮痧里：人呼吸让背向上，机器人却还在向下补偿，于是瞬间压过头（force spike）。

- **显式力/力矩控制（explicit force/moment control）**：一句话定义——不再靠"力误差换算成位置"这种绕弯子办法，而是直接对机器人下"用 5 牛的力、朝某个方向拧 2 牛·米"的命令。生活比喻：导纳像"踩软垫，你越用力陷越深"靠间接反馈；显式力控像直接对助手说"就用这么大劲"，一步到位。在刮痧里：这是超声论文用的强基线，FR5 因为是位置型机器人暂时没法原样抄，但可当"性能天花板"来比。

- **软体标准几何 + 实时形变（canonical geometry + live deformation）**：一句话定义——先存一个"标准姿势下的软体模型"，再单独叠加呼吸/受压产生的形变，两者分开管理。生活比喻：先做个静止的人体石膏模，再让它在上面实时鼓动模拟呼吸，而不是每次呼吸都重做一个新模。在刮痧里：背部既会呼吸起伏、又会被刮板压陷，用两层表示比"每次刚性对齐整条轨迹"更贴合真实物理。

- **频域体检 / 波特图（frequency-domain test / Bode plot）**：一句话定义——不只看"平均误差多大"，而是分不同频率（慢摆、快摆）分别看机器人跟不跟得上、差多少相位。生活比喻：考运动员不只看平均速度，还分"慢走、快跑、急停"各测一遍反应。在刮痧里：下一步要在 0.05–2 Hz（接近呼吸频率）扫频，看 FR5 导纳的真实表现。

- **正负刚度恒力机构**：一句话定义——把"越压越硬"的正刚度和"越压越软"的负刚度并联，叠加出一段"压深了力几乎不变"的近恒力区。生活比喻：像把弹簧和配重组合，压下 1 厘米和 5 厘米，手感力度几乎一样。在刮痧里：作为末端机械柔顺，先替软件吸掉高频抖动。

- **脱接触（loss of contact）**：一句话定义——恒力跟踪时刮板因补偿过头而短暂离开皮肤、接触力骤降为 0 的现象。生活比喻：你用手按弹簧想一直保持推力，手一抖弹开了，接触那一下就断了，力瞬间归零。在刮痧里：相位滞后严重时刮板会"跳"过背部再砸下来，造成力尖峰之后的脱空，是下一步频域体检必须记录的指标之一。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 动态机器人超声的强基线：motion-loop 才是真瓶颈

本轮最重要的新证据，来自 Piedra、Jeffrey、Khatib 2026 年发表于 IJRR 的机器人超声论文。超声探头要稳稳压在病人皮肤上做动态扫描，和刮痧板贴在背上恒力刮拭，几乎是同一个"贴软曲面 + 恒力 + 沿法向"的任务（术语表里叫"同构任务"）。

作者直接比较了两种做法：
- **传统导纳**（我们 FR5 现在用的思路）：靠"力误差 → 位置补偿"间接恒力。
- **显式力/力矩控制**：直接调探头接触力和力矩，并实时优化探头姿态。

结果很震撼：在超过典型呼吸频率的动态力跟踪里，**相位滞后从 121° 降到 5.76°**（121° 意味着"你起它落"几乎完全反相；5.76° 几乎是同步）；移动体模靠近/远离探头时，平均力误差分别降低 77.7% 和 72.6%。

**它在干什么、为什么聪明**：传统导纳把机器人当成"理想弹簧"来算，但真实机械臂底层还有个运动环（位置/速度伺服 + 通信），它自己就带延迟。就像你教徒弟手法再好，他耳朵到手的反应慢，整体还是慢半拍。**我们能抄什么**：FR5 是位置型机器人，没法原样复制"直接在力矩层下令"的控制器；但我们可以把这篇论文当成“外环导纳性能上限”的强基线——重点不是立刻换算法，而是先去测 FR5 自己到底慢多少。

**假如你是调试工程师**：你盯着示波器，看到目标力（绿色）和真实力（红色）在呼吸频率下像两条打架的蛇——绿色往上冲，红色慢半拍往下扎，交叉处冒出一根力尖峰的刺。你本能地把导纳的刚度 K 调低、阻尼 D 调高，曲线是软了，可尖峰只是变矮一点，相位差却纹丝不动。这时你才恍然大悟：问题不在你调的那几个旋钮，而在更底下那层运动环。这个“调了半天旋钮没用”的瞬间，正是本轮最想让你记住的顿悟。

### 3.2 软体双层形变表示：canonical + live deformation

第二篇 IJRR（Hu 等人 2026）解决的是"软东西会变样"的难题。过去我们可能把每次扫到的背部点云都用刚性 ICP 对齐到一个静态模型上（术语表里有 ICP：把两堆 3D 点对齐）。但软体大形变时，刚性对齐会把"不同姿态下的真身"错误融合成怪模。

作者改成两层：
- `S_ref`：接触前建立的"标准背部曲面"（静止参考）。
- `U_t(x)`：呼吸 + 受压引起的"局部形变场"（随时间变）。
- `S_live = U_t(S_ref)`：当前真实曲面 = 标准模被形变场推动后的样子。

**为什么聪明**：把"参考几何"和"瞬时几何"分离，人工画的线绑在标准模的固有坐标上，执行时再映射到实时曲面，比"每次呼吸都刚性重对齐整条轨迹"合理得多。**我们能抄什么**：第一版不用照搬整套非刚性 SLAM，只需在刮痧轨迹前方一段 corridor 里做"局部刚性 + 法向位移 / 低维形变场"，只有当残差超阈值才升级到非刚性配准。

### 3.3 软件柔顺不是唯一出路：机械柔顺做补充

Wu 等人 2025（Cyborg and Bionic Systems）做了个超声末端：主动控制 + 正/负刚度被动恒力机构并联。机械层先吸掉快速抖动，主动层只管慢尺度力设定、重力补偿和长行程。**ShapeForce**（ICRA 2026）更进一步：柔顺腕自身形变产生类力信号，专管高频接触扰动。

**为什么聪明**：外环延迟补不齐的高频扰动，加一点点"真弹簧"就能吸收，不必无限堆软件复杂度。**我们能抄什么**：这是 Plan B——如果真机测出 FR5 内环延迟是硬限制，就在刮板和力传感器之间加小行程、可建模的串联柔顺。但**第一代原型暂不改硬件，先把 FR5 测明白**。

### 3.4 把相机精度当真值？别急

RealSense 近距计量论文（Sensors 2021）按 ISO 标准在 10–150 厘米测了 D415/D455/L515，各指标优势不一致；更早真人面部实验约 1.46 mm RMS，35 厘米最好约 1.07 mm，且高曲率区会丢亚毫米信息。

**含义**：别预设 D435 在真人背部能给亚毫米真值。应自测一张误差图 `σ_z(距离, 入射角, 皮肤/标线纹理, 曝光)`，把它当作曲面拟合的权重（`w_i ∝ 1/σ_z,i²`）和视觉-力融合的置信度。毫米级深度误差靠曲面拟合 + 力柔顺吸收，系统误差则必须单独标定。

## 4. 关键算法/公式的直觉（大白话）

本轮两行核心公式，翻成白话：

1. 我们 FR5 外环导纳写成  
   `M_d·x'' + D_d·x' + K_d·x = F_d − F_n`  
   意思是：把"目标力 F_d 和实际法向力 F_n 的差"当成"弹簧力"，推动末端位置 x（M 是质量感、D 是阻尼、K 是刚度，都是虚拟参数）。**直觉**：你越用力压，它按弹簧规则多让一点。

2. 但真实机器人串了个内环 + 延迟：  
   `x_actual = G_r(s)·e^(−sτ)·x_cmd`  
   意思是：你下的位置命令 x_cmd，要先经过机器人内环 G_r、再被延迟 τ 拖后，才变成实际位置 x_actual。**直觉**：前面那套漂亮公式再完美，只要底层这个"慢半拍"在呼吸频率附近产生大相位差，就会出现"人背已上、机器人还向下补"的力峰值——**这不是调 M、D、K 能根治的**。所以下一步要拿移动软体体模，扫 0.05–2 Hz、不同振幅和刚度 K_e，记录目标力、实际力、命令位置、实际位置，画出力跟踪的增益/相位、峰值力、脱接触率、RMS 误差，把 plain / 限 jerk / 隐式欧拉三种导纳放同一频域实验里比。

几何层那行 `S_live = U_t(S_ref)` 的直觉：**标准模是"底图"，形变场是"实时推它变形的手"，两者相乘得"此刻真身"**，比反复刚性拼贴更贴近软组织物理。

**延迟项 `e^(−sτ)` 的比喻**：它就像你隔着一条走廊冲徒弟喊话，声音传到他耳朵要半秒、他反应又要半秒，等他动手，你原本指的"此刻"早过去了。无论你在前面把弹簧公式算得多漂亮，这半秒真空吞掉的就是"实时性"——而恒力贴软体这件事，恰恰最怕"不实时"。

## 5. 仍然没解决的坑 / 局限（2–4 条）

1. **FR5 真身没测过**：它的真实接口带宽 `G_r(jω)`、延迟、抖动到底多大，仍是假设。不测就不知道瓶颈真在软件还是硬件。
2. **D435 真实皮肤误差图没做**：文献只给通用代际数据，真人背部 + 彩色标线 + 斜入射下的 `σ_z` 必须自己标定。
3. **低维形变场是否够用未知**：只做局部低维 deformation 能否覆盖真实呼吸和接触形变，还是必须上完整非刚性配准，待验证。
4. **加机械柔顺会反伤观测**：若末端加了被动柔顺，可能削弱基于力矩的 CoP/接触估计可观测性——需要时得把柔顺机构位姿/形变量也纳入力矩变换。

## 6. 这一轮你该记住的 3 件事

1. **瓶颈可能不在算法，在运动环**：动态软组织下导纳的相位滞后是硬件级问题，先拿真机做频域体检，别盲目堆更复杂的 estimator。
2. **背部要分两层表示**：标准几何 S_ref + 实时形变 U_t，比每次刚性 ICP 整条轨迹更合理，第一版只做局部低维形变即可。
3. **机械柔顺是 Plan B 而非首选**：软件路线先测，实在卡住再加一点点末端串联柔顺，第一代原型不动硬件。
