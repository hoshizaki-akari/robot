# 第9轮：人体按摩直接 baseline——RGB 画线→深度反投影→B-spline→ICP 动态更新 + local surface 约束 + energy-tank 安全

> 学习目标：读完这一轮，你会明白"让机器人照着人在背上画的线去刮痧"已经有现成的真人按摩论文可以直接抄（baseline），以及我们该怎么在它的薄弱处做升级；同时理解为什么"深度补全网络"不能直接替我们决定刮板压在哪，而要用"局部曲面"作主约束，并学会用一个叫 energy-tank 的"能量池"给整条控制链路兜底保命。

## 1. 这一轮在解决什么问题（为什么重要）

前面几轮我们已经想好了一种做法：让人在摄像头拍到的背上画一条线，机器人把这条线变成三维路径，然后贴着背刮。听起来顺理成章，但有两个隐患一直没被坐实：

第一，**"人工画线→3D 轨迹"到底是我们的空想，还是真的有人做过？** 如果已经有人在人体按摩里完整跑通了，那我们就不用从零定义问题，直接把它当"参考答案"（baseline，见术语表）来对照和升级，能省下大量时间。

第二，**"深度图缺一块"时，该怎么补？** 我们的相机（D435）在彩色标线、反光皮肤、刮板遮挡处经常"看丢"深度，留出黑洞。一种诱人的做法是训练一个神经网络把整张深度图补全。但这一轮要告诉你：补全出来的深度不能直接决定刮板压在哪——那太危险。更稳妥的办法是**用"局部曲面"去约束那根线**，深度补全只能当辅助参考。

这一轮就干了两件事：① 找到了真人按摩里"RGB 画线→深度反投影→B-spline→ICP 动态更新"的直接 baseline（Xu 2024）；② 理清了"局部曲面约束 vs 逐像素深度补全"的主次关系，并给控制系统补上"energy-tank 安全层"和"宽刮板 partial slip 观测边界"两根保险丝。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

- **局部曲面约束（local surface constraint）**：一句话定义——要求那根轨迹必须"长在人体表面这块局部的弧面上"，而不是凭空悬空。生活比喻：你要在篮球表面上画一条线，线必须贴着球面走，不能飘在球外面。在刮痧里：人画的线只是"我想刮这儿"的意图，真实的三维位置得由背这块鼓起来的弧面来定，所以曲线要被"贴在背上"这个约束锁住。

- **深度补全（depth completion）**：一句话定义——把相机没测到的深度黑洞，用算法"猜"出填满。生活比喻：照片里被手指挡住的那块脸，你凭周围肤色脑补出来。在刮痧里：D435 看丢的地方，用网络补一张完整深度图；但它是"猜"的，不能直接拿来当刮板落点。

- **能量池 / 无源性（energy-tank / passivity）**：一句话定义——在控制器里设一个"能量账户"，只允许取用、不许透支，能量快超限就强制限力。生活比喻：给机器人装个"电量上限闸"，宁可它突然变僵，也不许它暴冲伤人的安全闸。在刮痧里：作为最底层安全层，保证就算上层算法抽风，刮板也不会突然猛压。

- **部分滑动（partial slip）**：一句话定义——接触区一部分粘住、一部分打滑的混合状态。生活比喻：鞋底一半踩实、一半打滑，你感觉"要滑又不滑"。在刮痧里：刮板压在背上时，板下可能局部开始打滑；这要靠板面内部不同位置的受力分布才能看清，单看手腕一个总力不够。

- **刚性 ICP（rigid ICP）**：一句话定义——假设人整个身体只是整体平移/转了一下，用"刚体变换"把旧轨迹挪到新位置。生活比喻：把一张贴好线的透明纸整体挪个位置，但纸本身不皱。在刮痧里：Xu 2024 在人动了一下后用 ICP 把整条轨迹搬过去；但人会呼吸、背会软陷，所以"整体搬"有时不够准。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 本论方法家族一：直接 baseline——Xu 2024 的"画线→轨迹"全流程

**它在干什么**：Xu 等人在真实机器人按摩里，完整跑通了这样一个流程——操作者在 RGB 彩色图上用鼠标画一条二维曲线（你想按摩的路线）；程序对线上每个像素读出它的深度，反投影回三维空间，得到一串三维点；再用人体的点云在轨迹点附近挑更靠谱的点修正一下；然后用最小二乘 B-spline 把点连成顺滑曲线；当人移动身体后，用相邻两帧人体点云做 ICP，算出"人挪了多少、转了多少"（R 和 t），把整条轨迹更新到新位置；最后用 PBVS（看目标、控位置）+ 法向力 PID（控压多深）混合控制真实机器人执行。

**为什么聪明**：它把"人画一条线"当作最自然的人机交互，不要求机器人自己聪明地规划路线，人指哪它刮哪，简单可靠。而且它考虑了"人会动"，用 ICP 在线更新，不是一次算死。

**我们能抄什么**：这就是我们的"第②主链路"最直接的参考答案。我们不必重新发明"画线→3D→更新"这套框架，而是站在它肩上，专攻它的薄弱处（见 3.2）。

### 3.2 本论方法家族二：把"局部曲面约束"换成主约束，深度补全降级

**它在干什么**：Xu 原方法对每个画线像素直接取它的深度 D(u,v) 当真值。但 D435 在彩色标线、反光皮肤、刮板遮挡、深浅边缘处常常"深度洞"跳变或失效。这一轮建议的升级是：RGB 上先分割出线条、变成有序折线；每个二维锚点不只查一个像素深度，而在它周围收集一批可靠深度样本；把这些样本和前方点云一起拟合成一小块局部曲面 S（用 MLS 或二次曲面）；再让相机射线和这块曲面求交点，得到三维锚点。如果交点残差太大、或周围有效深度太少，就标记为"低置信度"，宁可暂停重新看，也别让补全网络" hallucinate（凭空编）"一个深度。

**为什么聪明**：它把"曲线必须属于人体曲面"当成硬约束（p_i ∈ S），而不是"先瞎补深度再连曲线"。好比你要在篮球上画线，是先确认球面、再把线钉在球面上，而不是先凭空猜球外每个点离你多远再连线——后者一错就飘到球外了。

**我们能抄什么**：固定我们的画线链路为——RGB 线条分割 → 有序 2D 折线 → 深度可靠掩码 → 局部曲面 S → 射线–曲面交点锚点 → 带曲面约束的平滑 → 按弧长重采样 → 输出 {位置 p、切向 t、法向 n、姿态 R、置信度 c}。深度补全网络（如 Zhao 2024 的 SCMT、CVPR 2025 的 ProtoDepth）只作为"慢层候选/对照基准"，最终轨迹仍必须满足"点在看得见的人体曲面上"。

### 3.3 本论方法家族三：energy-tank + 变导纳的安全层

**它在干什么**：当我们以后想让系统"在线变软变硬"（变导纳）甚至上强化学习（RL）时，不能让学习部分直接发动作指令。这一轮找到 2026 年 FAAC 论文的做法：模糊/自适应逻辑只调"虚拟质量 M、阻尼 D"等参数，外面再套一个 energy-tank 可接纳滤波器，保证参数变化和接触切换时系统仍"无源"（不自发加能量）。UR10 抛光实验里，完整方法力标准差只有 2.76 N 且无接触丢失。另有 Nini 2025 把 energy-tank 和"安全阻尼注入"结合：交互能量/动能快超限时主动加阻尼耗散。理论靠山是 Roberts 2024 的采样–时延无源性边界：FR5 这种按固定周期"采样–计算–发令"的数字系统，稳定性不能只在连续数学里证明，必须把采样周期、注入延迟、环境刚度一起扫参验证。

**为什么聪明**：它把"学习/自适应"锁在最底层安全闸之后——任何自适应只输出候选参数 ΔM、ΔD、ΔF_d，必须经 energy-tank + 速率限制 + 力/速度硬上限 三道关才发给机器人。这样以后换 RL 也不用推翻安全结构。

**我们能抄什么**：在我们的状态机（前刮用力/轻力回程）之外，加一个 Safety Supervisor，至少同时盯 F_max（最大力）、v_max（最大速度）、e_edge（偏载）、E_interaction（交互能量）、timeout（超时）。即"宁可变僵，不可暴冲"。

### 3.4 本论方法家族四：宽刮板 partial slip 的观测边界

**它在干什么**：Aksoy 2024 用一条 1D 柔性传感阵列（每小格独立测法向+剪切），在 60–100 Hz 下能看到滑动从某一小格开始、再向别处传播，从而在完全打滑前认出"部分滑动"。这反过来给腕部 6D 力传感器 KWR75D 划了红线：它测的是整块接触区的"合力矩" W = ∫w(x,y)dA（把所有局部受力加起来），而 partial slip 依赖的是接触斑内部的 w(x,y) 怎么空间变化。许多不同的局部"粘/滑"分布，算出来的总力矩可能完全一样。

**为什么聪明（其实是"负结果"提醒）**：这告诉我们，第一阶段 KWR75D 只能老老实实估 F_n（法向力）、F_t（切向力）、p_CoP（压力中心）、e_edge（偏载）、τ_residual（残余力矩）、ρ_f（摩擦利用率）；不要把它包装成"能可靠检测 partial slip"。真要做 partial-slip 检测，得在刮板上加分布式剪切/触觉阵列当真值或在线传感。

**我们能抄什么**：明确我们的接触估计输出是上面那组"低维状态"，不夸大；未来若把 partial slip 当论文主贡献，先补硬件。

## 4. 关键算法/公式的直觉（大白话）

- **那条轨迹优化的式子**：min 后面跟三项。第一项 Σ‖π(p_i) − q_i‖² 是说"三维点投影回图像，要尽量对上你画的二维线 q_i"——保住你的意图；第二项 Σ‖p_{i+1} − 2p_i + p_{i−1}‖² 是"相邻三点别拐太急"，让曲线顺滑；第三项 Σ(‖p_{i+1} − p_i‖ − Δs)² 是"每段差不多长"，即按弧长均匀采样。λ_s、λ_l 是调和权重。一句话：让线既贴着你画的意图、又顺滑、又均匀，且每个点都钉在曲面 S 上。

- **刚性 ICP 更新 Γ' = RΓ + t**：人挪了一下，算出一个旋转 R 和位移 t，把旧轨迹整条搬过去。但当呼吸/软陷让背局部变形时，全局 ICP 看着不错、轨迹走廊里却残差很大，这时不能只搬，要重估局部曲面 S 再把二维意图重新投影上去。

- **energy-tank 可接纳**：自适应想改参数，先问能量池"还有余量吗？"有余量才放行，没余量就裁剪或拒绝。类比信用卡额度：刷爆了就拒付。

## 5. 仍然没解决的坑 / 局限（2–4 条）

1. **真实背部深度缺失到底多严重**：D435 在"真人皮肤 + 彩色标线 + 刮板遮挡"下的深度洞统计分布，本轮还没实测，只是推测会出问题。
2. **局部曲面法到底比直接反投影好多少毫米**：local MLS/mesh 投影相对原方法能改善多少，需要 A/B/C/D 四组消融实验（单像素反投影 / 邻域中位深度 / 局部 MLS 射线交点 / 曲面约束优化）用 0%/10%/30%/50% 人为缺失来回答。
3. **FR5 实测延迟与稳定域未知**：ServoCart 的指令–运动延迟、抖动多少，sampled-data 无源性边界在实际参数下长什么样，还得实机扫。
4. **partial slip 仍不可靠观测**：仅靠腕部 6D 合力，理论上无法稳定区分"整体摩擦变大"和"边缘开始局部滑移"，除非加装分布式触觉。

## 6. 这一轮你该记住的 3 件事

1. **"人工画线→3D 轨迹"已有真人按摩 baseline（Xu 2024）**，我们直接对照升级，不必从零发明；它的薄弱处（深度洞、刚性 ICP）正是我们的创新点。
2. **深度补全只能当辅助，局部曲面约束才是主约束**——曲线必须"长在背上"，低置信度就暂停，不许网络瞎编深度。
3. **任何自适应/学习只输出候选参数，必须经 energy-tank + 速率限制 + 力/速度硬限三道关**；且腕部 6D 力估不了 partial slip 细节，别夸大。

## 7. 和前后轮的关系
