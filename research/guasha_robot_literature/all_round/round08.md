# 第8轮：人工画线→3D 曲面轨迹、2D↔3D 映射、前视与逐级误差预算

> 学习目标：弄懂"人用笔画在背上的线，是怎么变成机器人能稳稳走的三维路径的"；学会用"逐级误差预算"的思路给误差分锅；并清楚认识到宽刮板靠一个腕部传感器只能估出"等效那一点"，没法还原整片压力分布。

## 1. 这一轮在解决什么问题（为什么重要）

上一轮（run7）我们已经把"从扫描背部、到真去刮"的整条技术链路打通了，也搭好了四层架构的骨架。但骨架里还缺一块最接地气的拼图：**人到底想让机器人往哪儿刮？**

设想一下真实场景：理疗师在患者背上用笔画出几条刮痧路线，说"就照着这几条线刮"。机器人眼睛（RGB-D 相机，见术语表）看到了这条彩色线，然后呢？它不能只把照片里"线在哪个像素"记下来就去刮——因为照片是平的，而人的背是弯的、软的、会随呼吸鼓动的。如果机器人傻傻地按"照片上的线 + 每个像素的深度"去走，遇到深度空洞（相机没测到距离）、飞点（测错了一个远点），轨迹就会断掉或乱跳。

这一轮要解决的，正是**"人画的二维线 → 能贴在三维背曲面上的顺滑轨迹"**这条转换链路，并且要把"最后轨迹偏了几毫米，到底是谁的锅"提前想清楚。它的重要性在于：这是人和机器人协作的第一个接口，接口不稳，后面再好的柔顺控制、恒力控制都救不回来。

## 2. 前置小知识（本论用到、读者可能不懂的概念）

下面 5 个词本轮第一次重点用到，先白话讲一遍。

- **逐像素深度反投影**：把"照片里一个像素"加上"它离相机多远"，直接还原成空间里的一个点。
  - 比喻：你对着照片说"这个红点离我 30 厘米"，于是把它摆在现实里 30 厘米处。
  - 在刮痧里：这是最朴素的做法，但它把轨迹"绑死"在每一颗噪点上了，深度一空洞轨迹就断——所以本轮要绕开它。

- **三角网格 + 重心坐标（barycentric）映射**：先把曲面切成一堆小三角形拼成"网"，再把一个二维点说成"落在某个三角形里、离三个角各有多远（三个权重加起来等于 1）"，靠这三个权重就能插回三维曲面上。
  - 比喻：把一张橘子皮剪成很多小三角，你只要说"我站在第 7 号三角里、离左下角近一点"，就能精确指回橘子皮上的位置。
  - 在刮痧里：这是把"画在平面上的线"稳稳贴回弯曲背部的关键数学工具。

- **前视（look-ahead）**：相机不只看"刮板脚下这一刻"的点，而是提前看刮板前方一段距离里的线和曲面，提前规划未来几十毫米怎么走。
  - 比喻：开车时你眼睛盯着前方 10 米而不是只盯车轮底下，才来得及拐弯。
  - 在刮痧里：因为刮板正好挡住真正接触的那块皮肤（遮挡，见术语表），看脚下反而看不到，看前方更合理。

- **误差预算（把误差拆账）**：不报一个笼统的"最终偏了 4 毫米"，而是把误差拆成若干来源，分别测、分别负责。
  - 比喻：菜做咸了，不笼统说"不好吃"，而是分别查盐放多了、酱放多了、还是火太大——下次才知道改哪一步。
  - 在刮痧里：最终轨迹偏了，要能定位是相机标歪了、还是深度不准、还是曲线没贴好曲面。

- **可观测性边界 / 等效接触点（CoP）**：一个传感器能反推出的信息是有上限的；"等效接触点"是把一整片接触压力等效成"一个合力作用点"（见术语表 CoP）。
  - 比喻：一群人一起推一扇门，你只能从门轴感受推出"合力大概作用在门的哪个高度"，但看不出每个人各自用了多大力。
  - 在刮痧里：宽刮板压在背上是一大片接触，腕部 6D 力传感器只能稳稳估出"等效那一点偏左还是偏右"，还原不出整片压力分布——这是数学上的硬限制。

## 3. 核心内容讲解（逐步、通俗，多用类比）

### 3.1 人工画线：从"描点"到"贴曲面"的方法家族

最笨的做法是：相机看到线在哪几个像素 → 每个像素去读深度 → 连成 3D 线。这就像用一串容易抖动的散点硬拼一条路，深度一空洞路就断。

本轮收敛出的更聪明结构是三步分工：

> **RGB 线条负责"人想走哪里" → 局部曲面（点云/网格）负责"这条线实际落在哪个弯背上" → 曲面约束优化负责"求出一条又顺又贴面的 3D 轨迹"。**

具体流水线：RGB 里把线分割出来 → 抽成 2D 骨架线 → 只取少量可信的 3D 锚点 → 把锚点投影到局部曲面/网格 → 用样条（B-spline，见术语表，像按图钉弯出的软尺）连成顺滑曲线 → **按弧长重采样**（后面讲为什么）→ 算出每一点的切线、法向、刮板姿态。

它能抄什么：**第一版就用"RGB 提意图 + 网格投影 + 样条"这条最稳的路线**，别一上来追求酷炫。

### 3.2 2D↔3D 映射：把背"展平"再画回去（LSCM / 重心坐标）

本轮最亮眼的一篇新论文（Shen 等，2026）给了第二条漂亮 baseline。思路是：先把背部一小块点云变成三角网格，再用"最小二乘保角映射（LSCM）"把这块弯曲面**尽量不变形地展平到一张二维图**上；人在这二维图上规划线，然后靠"重心坐标"（就是第 2 节那个橘子皮三角的比喻）把每个点插回原三维曲面。

为什么比"逐像素读深度"聪明？因为线被定义在**连续的曲面**上，而不是定义在**一组会出空洞的噪点**上。哪怕线条跨过一小片深度空洞，只要曲面网格连续，线就不断。

另一个更进阶的 baseline（Azariadis 等，2026）连网格都不用建，直接在带方向的点云上算"贴着曲面的最短曲线"。本轮建议：**论文阶段再拿来和网格法对比，第一版工程仍用网格投影，简单可靠。**

我们能抄的改造版是：`操作者的 RGB 线 → 映射到参数域 → 重心坐标反算回 3D 曲面`，而不是 `(像素, 深度)→XYZ` 这种脆弱写法。

### 3.3 前视相机：看刮板前方，而不是脚下（Eye-in-Hand look-ahead）

经典论文（Lange & Hirzinger, 2003）的做法很启发：单目手眼相机不只盯当前线点，而是利用**前方已经看到的线段**做多项式预测，同时考虑相机采样慢、图像处理有延迟、机器人本身会跑偏。

落到我们的设计上：D435（见术语表 RGB-D 相机）应该维持一个 `50–150 毫米` 的前视窗口，看刮板前方那一段线和曲面，提前生成未来轨迹与法向。因为**刮板正好挡住真正接触的那块皮肤**（遮挡），"始终看 TCP 下方"反而看不到真接触点，看前方更合理。

### 3.4 力控能补几何误差，但不能掩盖系统误差

一篇实机论文（Zaki 等, 2023，UR5e + RealSense D415）给出重要边界：低成本 RGB-D 重构出的轨迹，平均误差约 1.1–1.3 毫米、最大约 3 毫米，而闭环力控可以进一步补偿毫米级的深度误差。

但本轮划了一条红线：**力控可以补偿小的法向几何误差，不能拿来掩盖 hand-eye（手眼标定）、TCP（工具中心点，见术语表）、线条定位的系统性偏差。** 所以以后论文必须同时报"几何轨迹误差"和"力误差"两份账，不能只说"最后贴住了就算准"。

### 3.5 宽刮板可观测性边界：只能估"等效那一点"

这是本轮一个必须说清的"清醒认识"。一个腕部 6D 力/力矩传感器（见术语表 6D F/T）配"已知工具几何"，对于**单点刚体接触**能靠 `力矩 = 力臂 × 力`（τ=r×f）定位接触点。但对于**宽刮板压在软皮肤上的线/面分布接触**，六个 wrench 分量其实只是整片压力、摩擦分布的"六个加总量"（积分）。

因此第一阶段我们能**老实宣称**的只有四项：合力 F、等效压力中心 CoP / 作用线交点、残余力矩、偏载指示（板压歪没）。**绝不能在没加触觉阵列的情况下，声称还原了整片皮肤压力分布 p(x,y)**——线/面接触的压力分布自由度是无限的，而传感器只有 6 个量，这是结构性不可观测，换再好的滤波器或神经网络也救不回来。

## 4. 关键算法/公式的直觉（大白话）

**曲面约束优化的目标函数**（求 3D 曲线 Γ 上每个点 p_i）：

`min Σ‖p_i − p_i^raw‖² + λ_s Σ‖p_{i+1}−2p_i+p_{i−1}‖² + λ_g Σ d(p_i, S)²`

别被符号吓到，三项就是三个"既要又要"：
- 第一项：别偏离操作者画的原始线（保意图）；
- 第二项：曲线要顺滑，别抖（像软尺弯出来而不是折线）；
- 第三项：曲线必须贴在背部曲面 S 上（d 是到曲面的距离）。
三个权重 λ 就是"更听人的、还是更顺、还是更贴面"的旋钮。

**为什么必须按弧长重采样**：人画线时手快手慢不一，像素密度不均。若把每个像素都当路点，机器人局部速度会跟着人画画的快慢乱变。改成"沿路径每走固定长度 Δs 取一个点"（`s_i = i·Δs`），速度和姿态更新率就稳了——就像用地图上"每走 5 公里"设一个路标，而不是"每过一个电线杆"。

**逐级误差预算公式**：`e_total ≈ J_seg·e_seg + J_depth·e_depth + J_HE·e_HE + J_reg·e_reg + J_proj·e_proj + J_TCP·e_TCP`。意思是：最终误差是"分割误差 + 深度误差 + 手眼误差 + 网格/参数化误差 + 曲面投影误差 + TCP 误差"按各自敏感度（J）加起来的。实机不必第一版就推完整协方差，分别测这六项再相加即可，偏了就知道该优化哪块。

## 5. 仍然没解决的坑 / 局限（2–4 条）

1. **真实皮肤上的深度空洞有多大，还没测**：D435 在"真皮肤 + 彩色标记线"条件下，线条附近深度空洞/偏差到底多大，只能等实机验证；理论再美也得过这一关。
2. **LSCM/网格法是否真比直接反投影好，待比**：目前只是"应该更稳"的推断，要在人体背部实机对比才有结论。
3. **FR5 的真实延迟/抖动未知**：sampled-data（离散采样，见术语表）、deadtime（死区时间）、jitter（抖动）会直接改写导纳外环的稳定域，但 ServoCart 的实际数值随网络/SDK/语言变，必须实测才能画出稳定图。
4. **宽刮板压力分布不可唯一恢复是结构性限制**：已确认靠单个腕部传感器无解，是否要上第二代薄型触觉阵列，仍是开放问题。

## 6. 这一轮你该记住的 3 件事

1. 人画的线别"逐像素读深度"去走，而要 **RGB 表达意图 + 局部曲面提供几何 + 曲面约束优化** 三步走，轨迹才稳。
2. 误差要**逐级预算、分锅到模块**（分割/深度/手眼/投影/TCP），最终偏了才能定位改哪；力控能补几何小误差，但**不能掩盖系统误差**。
3. 宽刮板配单腕 6D 传感器，**只能稳估等效 CoP/合力与偏载，还原不了整片压力分布**——这是数学硬限制，别过度宣称。

## 7. 和前后轮的关系

- **承接**：run7 打通了"从扫到刮"全链路与四层架构，但"人画的线怎么变成机器人能走的 3D 轨迹"还是空白。本轮正好补上这一最前端的协作接口，并给出了从"看线 → 贴曲面轨迹 → 力矩观测 → 接触估计 → 采样/延迟感知导纳 → 状态机 → 安全层"的完整软件结构。
- **铺垫**：为 run9 埋下三处伏笔——①直接拿 Zhai 等（2026）的"人体背部按摩"当 baseline 对标，并瞄准其"缺 formal passivity/Lyapunov 证明"的缺口；②用"局部曲面约束（local surface constraint）替代逐像素深度补全"作为下一轮主攻；③把 energy-tank（能量池，见术语表）安全层正式列为可超越现有 baseline 的杀手锏。
