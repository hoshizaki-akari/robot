# 刮痧机器人学习术语表（零基础白话版）

> 用途：本术语表是所有"逐轮教学模块"的统一口径。读到不懂的词，先来这里查。
> 约定：每个词都给「一句话定义 + 一个生活比喻 + 在刮痧里它指什么」。

---

## 一、基础概念

**刮痧（Gua sha）**
- 定义：中医的一种理疗手法，用牛角/玉石等工具在皮肤表面反复刮拭，制造可控的按压与摩擦刺激。
- 比喻：像用汤勺背面在背上"刮"出红印，目的是松解筋膜、促进循环。
- 在刮痧里：机器人的活，就是把人手的这套"刮"自动化、可量化。

**刮痧机器人**
- 定义：用机械臂 + 传感器，代替或辅助人完成刮痧的自动化系统。
- 比喻：一个"不知疲倦、力度恒定、不会手抖"的按摩师。
- 在刮痧里：本项目的主角，核心是"看得见曲面、摸得清力、刮得稳"。

**机械臂 / 工业机械臂**
- 定义：由多个关节串联、能在空间里移动末端的机器人手臂。
- 比喻：像人的胳膊，大臂小臂手腕配合把"手"放到想要的位置。
- 在刮痧里：FR5 是本项目用的具体型号（一个六自由度的国产协作/工业臂）。

**末端执行器（End-effector）**
- 定义：装在机械臂最前端的"手"，真正干活的部分。
- 比喻：胳膊尖上的那只手。
- 在刮痧里：就是"刮痧板 + 力传感器 +（可能有的）相机"这一整套。

**TCP（Tool Center Point，工具中心点）**
- 定义：我们约定用机械臂去控制的那一个"关键点"，通常是工具尖/工具工作面的中心。
- 比喻：写字时你盯着的"笔尖"，机器人所有动作都围绕这个点算。
- 在刮痧里：过去把板当成一个点（笔尖）来控；后来发现板有宽度，不能只当一个点。

**自由度（DoF, Degree of Freedom）**
- 定义：一个物体能独立运动的方向数（上下、左右、前后 + 转来转去）。
- 比喻：人胳膊能伸、能转，方向越多越灵活。
- 在刮痧里：6 自由度 = 能到任意位置、摆任意朝向；6D 传感器因此对应 6 个量。

## 二、传感器与感知

**6D F/T（六维力/力矩传感器）**
- 定义：同时测 3 个方向的力（推/拉）和 3 个方向的力矩（拧/扭）的传感器。
- 比喻：一块"智能秤"，不但称你压了多重，还称你往哪边歪、拧了多大劲。
- 在刮痧里：装在腕部的 KWR75D，就是机器人的"触觉"，靠它知道刮板压得多重、压歪没。

**力（Force）/ 力矩（Torque / Moment）**
- 定义：力是"推或拉"；力矩是"力作用在偏离中心时造成的转动趋势"，关系为 τ = r × f（力臂 × 力）。
- 比喻：推门：正推门把手（力）容易开；离铰链越远（力臂越大）越省劲（力矩大）。
- 在刮痧里：板压在皮肤上产生"力"；板压歪了、一边重一边轻，就产生"力矩"，力矩能反推出"板压在哪儿、偏没偏"。

**法向（Normal）**
- 定义：垂直于某个表面的方向，即"正对着表面、直直戳出去"的那条线。
- 比喻：贴在墙上的图钉，钉尖指向墙外的方向就是墙面的法向。
- 在刮痧里：刮痧要顺着背部曲面的"法向"压下去才稳、才不刮伤；法向估错，板就斜着戳皮肤。

**切向（Tangential）**
- 定义：贴着表面、沿着表面的方向（与法向垂直）。
- 比喻：手在桌面上滑动的方向。
- 在刮痧里：刮痧的"刮"动作主要在切向滑动；切向力/摩擦过大会带来干扰。

**RGB-D 相机**
- 定义：普通彩色相机（RGB，看颜色）加上深度通道（D，测每个像素离相机多远），输出"带距离的照片"。
- 比喻：不但拍下你长什么样，还知道你鼻子离镜头 30 厘米。
- 在刮痧里：本项目用 Intel RealSense（D435 一类）看背部曲面、算法向、把人画的线变成 3D 轨迹。

**Eye-in-Hand（手眼相机）**
- 定义：把相机装在机械臂手上，跟着手一起动。
- 比喻：把眼睛长在手上，手伸到哪看到哪。
- 在刮痧里：好处是贴近看曲面；坏处是刮板会挡住真正接触的那块皮肤（遮挡问题）。

**深度反投影（Depth back-projection）**
- 定义：用相机内参，把"图像里的一个像素 + 它的深度"还原成空间里的 3D 点。
- 比喻：知道照片里一个点、又知道它离你多远，就能在现实里标出它的位置。
- 在刮痧里：人在背上画的线，靠反投影变成机器人能走的三维路径点。

**遮挡（Occlusion）**
- 定义：视线被挡住，看不到想看的地方。
- 比喻：手挡在脸前，相机就拍不到脸。
- 在刮痧里：刮板正好挡住接触区，所以"视觉看不到接触点"要靠力觉补。

## 三、控制方法

**柔顺控制（Compliance Control）**
- 定义：让本来硬邦邦的机器人"变软"，碰到曲面能顺着让一让。
- 比喻：硬棍戳墙会梗住，软弹簧能贴着墙歪过去；柔顺就是让臂像弹簧。
- 在刮痧里：背是软的、是弯的，臂必须柔顺才能贴着刮而不戳伤。

**恒力控制（Constant Force Control）**
- 定义：不管曲面怎么起伏，都让工具以稳定的力压在表面上。
- 比喻：无论桌面平不平，都只用同样的劲按住。
- 在刮痧里：刮痧要"力度恒定"，太轻没用、太重伤人，所以恒力是关键指标。

**导纳控制（Admittance Control）**
- 定义：给定"外力→产生运动"的关系，机器人像被弹簧拉着：你推它，它按弹簧规则让开。
- 比喻：踩在会下陷的软垫上，你越用力踩，垫子陷得越深、你的脚越往下走。
- 在刮痧里：把"力误差"换算成"该往法向多压/少压多少"，实现恒力贴面。常作外环（低频）。

**阻抗控制（Impedance Control）**
- 定义：给定"运动→产生力"的关系，机器人像弹簧一样抵抗：你让它位移，它回弹出力。
- 比喻：压弹簧，压得越深回力越大。
- 在刮痧里：和导纳是"镜像"——导纳是力控位置，阻抗是位置控力；本项目多用导纳作外环。

**变阻抗 / 变导纳（Variable Impedance/Admittance）**
- 定义：上面的"弹簧软硬"不是固定值，而随情况在线调整。
- 比喻：遇到硬骨头把垫子调硬，遇到软肉调软。
- 在刮痧里：前刮/回程不同，需要的软硬不同，所以参数要在线变。

**位置控制机器人（Position-Controlled Robot）**
- 定义：只能接收"到某个位置"指令、内部自带伺服的机器人（不能直接下令"用 5N 力"）。
- 比喻：只会听"把手移到这儿"，不会听"用多大劲"。
- 在刮痧里：FR5 就是这类；所以恒力要靠"导纳外环把力误差变成位置指令"来间接实现。

**状态机（State Machine）**
- 定义：把任务分成几个"状态"，按条件切换，同一时刻只在一个状态。
- 比喻：洗衣机有"进水→洗涤→脱水→结束"，一步步切。
- 在刮痧里：刮痧分成"前刮（用力）"和"轻力回程（收力返回）"等状态，各用不同力度/速度。

## 四、估计与滤波

**接触状态估计（Contact State Estimation）**
- 定义：从传感器数据反推"工具此刻在哪儿接触、压多重、偏没偏、法向对不对"。
- 比喻：闭着眼摸一个球，靠手感猜球在心口哪、压了多实。
- 在刮痧里：机器人的核心智能——靠 6D 力和视觉，实时猜"板正贴在背上哪、压歪没"。

**等效接触位置 / CoP（Center of Pressure，压力中心）**
- 定义：分布在一片接触区上的压力，可以等效成一个"合力作用点"，就叫等效接触位置或压力中心。
- 比喻：一群人推一扇门，合力效果等价于"某一个人用总力推在门上一点"。
- 在刮痧里：宽刮板压在背上是一片接触，6D 力矩只能稳稳反推出"等效那一点在哪、偏左还是偏右"，不能还原整片压力分布（这是本项目的硬限制）。

**偏载（Edge Load / Eccentricity）**
- 定义：工具压在接触区的一边比另一边重，受力不均。
- 比喻：凳子一条腿悬空，人坐上去就歪。
- 在刮痧里：刮板压歪了，力矩会暴露"偏左/偏右"，这正是要纠正的信号。

**EKF / UKF / PF（滤波器）**
- 定义：三类"边测边估"的算法，从带噪声的测量里估计随时间变化的隐藏状态。
  - EKF（扩展卡尔曼）：最常用的线性化递推估计。
  - UKF（无迹卡尔曼）：对非线性更稳。
  - PF（粒子滤波）：用一堆"候选假设粒子"投票，适合高维/多峰。
- 比喻：雾里看人走路，每帧照片都糊，但你按"人一般不会瞬移"把多帧拼起来，就估出他真实位置。
- 在刮痧里：把"接触位置/法向"当隐藏状态，用历史力+运动+几何持续估计，而不是信单帧。

**MPC（Model Predictive Control，模型预测控制）**
- 定义：每步都"向前算几步、选一组最优控制"，再只执行第一步，滚动进行。
- 比喻：下棋每步走之前先想后几招，选最优那步。
- 在刮痧里：用于刚-软异质接触等需要"看前几步"的场景。

## 五、几何与轨迹

**B-spline（B 样条）**
- 定义：穿过/贴近一串控制点的光滑曲线，局部可调、不会整体抖。
- 比喻：一根有弹性的软尺，按几个图钉弯出顺滑的弧。
- 在刮痧里：把人画的离散点连成顺滑可走的刮痧路径。

**ICP（Iterative Closest Point，迭代最近点）**
- 定义：把两堆 3D 点云对齐的算法，反复找最近点、算最佳刚体变换。
- 比喻：把两张透明描摹纸叠一起，反复挪到轮廓最重合。
- 在刮痧里：把实时扫到的曲面和已有模型对齐，动态更新轨迹。

**MLS（Moving Least Squares，移动最小二乘）**
- 定义：在每个点附近用最小二乘拟合一个局部光滑曲面。
- 比喻：用一段段小直尺拼出一条弯弯曲曲的滑道。
- 在刮痧里：从嘈杂点云里算出每个位置的局部法向。

**SLERP（球面线性插值）**
- 定义：在两个朝向（姿态）之间做匀速、不抖的插值。
- 比喻：方向盘从朝东平滑转到朝南，不突兀。
- 在刮痧里：让刮板姿态沿轨迹平滑过渡，避免抖。

**人工标线 → 3D 轨迹**
- 定义：人在背上画好刮痧路线，机器人用相机把线变成三维路径。
- 比喻：你先在背上用笔画好道，机器人照着道走。
- 在刮痧里：本项目的人机协作起点，避免机器人自己乱规划。

**弧长参数化（s 参数）**
- 定义：用"沿路径走了多长"而不是"第几个点"来标记位置。
- 比喻：用地图上"走了 5 公里处"而非"第 5 个路标"定位。
- 在刮痧里：让位置、姿态、力度、速度都跟着"走了多远"同步变化，前后刮/回程连续。

## 六、安全与系统

**deadtime / latency / jitter（死区时间 / 延迟 / 抖动）**
- 定义：指令发出到执行/反馈回来的时间差叫延迟；不稳定叫抖动；固定空白叫死区。
- 比喻：按开关灯过半秒才亮（延迟），有时快有时慢（抖动）。
- 在刮痧里：FR5 的网络/伺服有延迟，导纳外环频率被它卡住，是实机瓶颈。

**sampled-data / 离散时间（采样/离散控制）**
- 定义：控制不是连续跑，而是按固定周期"采样—计算—发令"一步步走。
- 比喻：动画是一帧帧播，不是真连续。
- 在刮痧里：导纳在 50–100 Hz 这样的离散频率跑，稳定性要按离散分析。

**passivity（无源性）/ energy-tank（能量池）**
- 定义：无源性=系统不自发往里加能量；能量池=在控制器里设个"能量账户"，只允许取不许透支，超了就限力。
- 比喻：给机器人装个"电量上限"，宁可变僵也不许暴冲伤人的安全闸。
- 在刮痧里：作为安全层，保证即使算法出错也不会突然猛压。

**同构任务（Isomorphic Task）**
- 定义：结构相似、可互相借鉴的不同任务。
- 比喻：拖地与擦窗动作像，手法能互通。
- 在刮痧里：机器人抛光、超声探头贴合、擦洗，都和刮痧"贴曲面+恒力+沿法向"同构，是主要参考文献来源。

**baseline（基线）**
- 定义：拿来作对比的"基础方法/参照实现"。
- 比喻：考试的对照片，看自己进步没。
- 在刮痧里：每轮都会指出现成论文里的 baseline 能直接抄哪段。

**partial slip（部分滑动）**
- 定义：接触区一部分粘住、一部分打滑的混合状态。
- 比喻：鞋底一半踩实一半打滑。
- 在刮痧里：腕部 6D 合力对"部分滑动"有结构性观测限制，估不清细节。

**soft-object canonical geometry + live deformation（软体标准几何 + 实时形变）**
- 定义：先有一个"标准姿势下的软体模型"，再实时叠加呼吸/受压产生的形变。
- 比喻：先有个人体石膏模，再实时让它随呼吸鼓动。
- 在刮痧里：处理背部随呼吸起伏、被板压陷的时变曲面。

## 七、动态接触与实时控制

**交互/接触坐标系（Interaction/Contact Frame）**
- 定义：以当前工具—环境实际接触位置及局部方向建立的坐标系；当接触点迁移时，坐标系也随之更新。
- 比喻：扫帚头在地面上移动时，要跟着刷毛真正碰地的位置算误差，而不是只盯住扫帚柄末端。
- 在刮痧里：以等效压力中心 CoP 建立局部接触框架，位置、姿态、速度、wrench 和 Jacobian 的参考点必须一致。

**相位滞后（Phase Lag）/ 频率响应（Frequency Response）**
- 定义：目标信号与真实输出在周期变化中的角度错位；频率响应同时描述不同变化速度下输出幅值与相位如何改变。
- 比喻：你喊“现在停”，机械臂晚一拍才停；慢动作时问题不明显，动作变快就会过冲。
- 在刮痧里：通过多个频率的小幅安全激励，测 FR5 的命令—实际位置与目标力—实测力响应，判断导纳外环能否跟上呼吸和局部起伏。

**加加速度 / Jerk Limiter**
- 定义：加速度随时间的变化率；jerk limiter 限制位置/速度命令的突变程度。
- 比喻：电梯不是瞬间“猛地一蹿”，而是平滑地起步和停下。
- 在刮痧里：降低接触建立、转向和力模式切换时的冲击；具体限值需根据 FR5 的运动接口和体模试验确定。

**Wrench 参考点变换**
- 定义：将力与力矩从一个参考点移到另一个参考点时，需要按力臂关系同步修正力矩，并统一力、力矩的表达坐标系。
- 比喻：同样推门，换一个施力位置，围绕转轴的转动力矩就会改变。
- 在刮痧里：从腕部传感器原点转到刮板等效 CoP 时，要先校验坐标系和正负号；不能只平移接触点而保留旧力矩。
