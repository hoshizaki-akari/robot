# 刮痧机器人深挖追踪 — 2026-09-25 Run 06

## 本轮自适应重点

本轮在既有 Run 03–05 基础上避免重复，重点补三个薄弱环节：

1. **人体背部真实同构系统**：接触点 + 表面法向在线估计、接触过渡、变阻抗/混合力位控制是否已有直接人体背部验证；
2. **刮板滑动接触的可观测性**：摩擦存在时，F/T 合力方向不能直接当真实法向；需要 force + velocity + geometry/vision 的 friction-aware 估计；
3. **KWR75D 上线前的 wrench 前处理**：payload mass/CoG、force/torque bias、坐标变换、滤波必须成为独立标定层，否则后续 CoP/法向/力矩算法都会被污染。

本轮最重要的新发现是 2026 年 Frontiers in Robotics and AI 的人体背部理疗工作：它已经把 **F/T 接触点估计、速度反馈法向估计、接触前动态减速、力误差补偿、bounded variable impedance** 集成，并在硅胶模型和健康志愿者背部做了验证。它与当前刮痧主链路高度同构，应该升级为新的直接 baseline；我们的创新空间则转向 Eye-in-Hand 视觉先验、刮板宽接触/CoP、摩擦感知法向、人工画线三维轨迹和双向前刮/轻力回程。

## 1. S+ — Zhai et al., Contact-aware multi-skill learning framework with hybrid force-motion control for stability and force regulation in robotic physiotherapy

- **类型**：期刊论文，Frontiers in Robotics and AI, Vol.13, 2026
- **作者**：Xueqian Zhai, Qihao Feng, Haochen Zheng, Yi Luo, Huikun Hao, An Yan, Hongmin Wu
- **发布日期**：2026-08-06
- **DOI**：10.3389/frobt.2026.1892296
- **官方链接**：https://doi.org/10.3389/frobt.2026.1892296
- **输入**：DMP 任务轨迹、机器人状态、末端六维 F/T、速度反馈
- **输出**：估计接触点、估计表面法向、动态接近速度、力误差补偿、时变阻抗/机器人动作
- **核心思想**：将按摩技能 DMP、F/T 接触点与法向估计、接触前动态减速、force-error compensation、bounded variable impedance 串成统一闭环，而不是把“接触建立”和“恒力执行”割裂处理。

- **实机性**：高。论文使用 Franka + 6D F/T，并在硅胶模型和 1 名健康志愿者背部做 preliminary feasibility/safety test。
- **复现难度**：中高。公式可复现，但未核验到作者公开完整代码。
- **局限**：论文的接触末端接近点/拇指式工具，尚未处理刮板的宽接触线/面；人体实验仅初步可行性，不是临床证据；未引入 RGB-D 几何先验。

# 本轮结构化精读：Zhai et al. 2026

这篇现在是当前链路最重要的“直接人体背部同构 baseline”。其结构不是单一按摩轨迹，而是：

`DMP nominal skill -> F/T contact point & normal estimator -> local task frame update -> dynamic approach velocity -> force-error compensation -> bounded variable impedance -> robot`。

最值得迁移的不是 DMP，而是 **接触状态估计与控制状态机耦合**。

论文首先明确工具端相对机器人末端的位置必须已知，并在 F/T wrench 中补偿工具重力和质心产生的力矩，然后利用 contact force/moment 更新接触点。随后又通过 end-effector velocity feedback 逐步更新 surface normal，使 contact force 可以分解为 normal deformation force 与 tangential/friction force。换句话说，它已经明确支持：

`wrench + motion -> contact point + normal -> local task frame`。

它还将接触建立单独处理：接近目标时不是保持固定高速直到触碰，而是分阶段连续减速，再在接触后细调速度，以避免冲击和反向 force compensation 引起的上下振荡。最后，force-error compensation 和 bounded variable impedance 再负责持续交互。

对当前刮痧机器人的直接改造应是：

1. **DMP 换成人工画线 3D 曲线 Γ(s)**。我们的 nominal motion 已由操作者明确给定，不需要先学习按摩动作；
2. **点状 contact point 换成 scraper equivalent CoP / edge-load state**。宽刮板不应假定单点接触；
3. **F/T-only normal 增加 D435 n_v 先验**。在轻力回程、U-turn、低速度时，force-motion estimator 可观测性下降，此时视觉权重提高；
4. **增加 friction-aware decomposition**。Forward 滑动中 F_t 是任务本身的一部分，不能简单当扰动消掉；
5. **状态机明确分成 Approach / Touch / Ramp / ForwardScrape / Turn / LightReturn / Exit**，每个状态分别调 `F_d, v_t, visual-force fusion weight, stiffness/admittance parameters`。

这篇论文还给出了一个重要边界：它的健康志愿者背部实验只是 preliminary feasibility/safety validation，不能当临床疗效证据。因此我们的早期论文也应把目标写成机器人接触控制、几何/力觉估计与安全性能，而不是医学疗效。

# 对总体路线的影响

本轮后，第一阶段不应再把“法向估计器”当成一个孤立模块。更合理的是构造 **状态相关的局部接触坐标系估计器**：

`x_c = [n_hat, p_CoP, F_n, F_t, tau_res, contact_confidence]`

视觉慢层提供 `n_v, local quadratic surface, curvature, look-ahead geometry`；F/T 快层先经过 payload/CoG/bias/gravity compensation，再提供 wrench；运动历史提供 `v_t` 和当前状态机 phase。融合权重不是常数，而由 `|F_n|, |v_t|, wrench SNR, visual confidence, state` 决定。

建议状态机参数化为：

- Approach：视觉主导，F_d=0，速度渐降；
- Touch：检测 contact onset，限制 impact；
- Ramp：F_d 平滑升至 F_scrape；
- ForwardScrape：friction-aware visual-force fusion，恒力 + 切向轨迹；
- Turn：v_t→0，降低 force-motion normal estimator 权重，姿态/力连续过渡；
- LightReturn：F_return << F_scrape，因 wrench SNR 下降而提高视觉权重；
- Exit/Fault：独立 safety supervisor 回撤。

# 已有文献支撑 vs 待验证工程假设

## 已有较强支撑

- F/T + velocity feedback 可以在未知曲面上在线估计/修正 surface normal；
- 人体背部理疗任务已经实机验证“contact point/normal estimation + dynamic approach velocity + force compensation + variable impedance”的整体框架；
- RGB-D normal 存在误差时可用 F/T 接触反馈修正工具姿态；
- 滑动摩擦会污染基于合力方向的法向估计，因此需要 friction-aware 分解；
- 工具 payload mass、CoG 与 F/T bias 必须在接触算法之前补偿；
- 位置控制机器人上的外环 admittance 会受到底层 motion loop、时延和离散实现影响。

## 仍需自己实验回答

1. KWR75D 在 F_return 轻力状态下 torque SNR 是否足以支持 CoP/姿态失配估计；
2. 宽刮板软组织滑动时，等效 CoP 偏移能否稳定区分“姿态倾斜”与“皮肤剪切/摩擦/局部形变”；
3. FR5 ServoCart 实际 command-to-motion delay、jitter 与可持续控制频率；
4. 单 D435 Eye-in-Hand 在刮板遮挡下 look-ahead 二次曲面预测的有效距离 Δs 与法向时间稳定性；
5. 人工画线在皮肤变形/遮挡/反光条件下，2D→3D 曲线映射误差的主要来源究竟是颜色线检测、深度噪声还是 hand-eye/registration。

# 下一轮自适应重点

1. **FR5 实际接口约束 + sampled-data/passivity**：继续寻找能够给出 `T_s, delay, K_e, M_d,D_d,K_d` 稳定关系的可计算方法，并尽量对应位置伺服工业机器人；
2. **宽刮板 soft distributed contact**：重点追 center-of-pressure、residual moment、line/patch contact observability，而不是继续堆 point-contact 文献；
3. **画线轨迹误差预算**：开始把 2D segmentation → depth backprojection → hand-eye → surface projection → B-spline/arc-length resampling 的误差逐级量化，形成可以直接做实验的 error budget。

RL / residual RL 继续保持低优先级，直到 geometry-contact-control baseline 能在 phantom 上稳定闭环。
