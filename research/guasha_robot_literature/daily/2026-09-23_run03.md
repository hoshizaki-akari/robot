# 刮痧机器人深挖型文献追踪 — 2026-09-23 / Run 03

## 本轮自适应检索重点

本轮没有继续泛搜按摩机器人，而是集中补三个薄弱环节：

1. **宽刮板/工具接触位置与接触形态估计**：6D wrench 是否能从腕部反推刮板实际受力位置、偏载和姿态失配；
2. **未知曲面上的法向—姿态—恒力同步控制**：尤其是无需精确 CAD、利用接触力矩在线修正局部法向；
3. **位置控制工业机械臂的可部署柔顺控制**：低频、延迟、死区条件下的离散导纳与安全实现。

本轮最重要的新判断：**刮板不应只建模为一个 TCP 点，而应建模为“已知工具几何 + 在线等效接触位置/接触线 + 局部接触坐标系”**。腕部 6D F/T 的 torque 不是附属信号，而是 contact location / posture mismatch 的核心观测量。

## 1. S+：Simultaneous estimation of contact position and tool shape with high-dimensional parameters using force measurements and particle filtering

- 作者：Kyo Kutsuzawa, Mitsuhiro Hayashibe
- 年份：2026（online 2025-09-27；IJRR 45(7), 1046–1062, 2026）
- 载体：The International Journal of Robotics Research
- DOI：10.1177/02783649251379515
- 类型：正式期刊论文
- 推荐优先级：S+

### 核心方法
传统 intrinsic contact sensing 常假设工具几何已知。该工作进一步把**接触位置和工具形状一起估计**：工具表面用超过 1000 维的 grid 参数表示，用 particle filter 避免直接在整个高维空间做优化；每个粒子携带自己的工具形状假设，并利用力测量随接触运动持续更新。实验在曲面工具与平面接触上验证，工具形状估计改善后，接触位置估计也随之提高。

### 对刮痧的迁移
我们的刮痧板几何原则上是已知的，因此无需照搬高维工具形状估计；反而可以把问题大幅简化为：

`known scraper geometry + measured wrench -> contact coordinate / edge load state`

真正值得借鉴的是它的**概率状态估计思想**：不要把单帧 `tau = r × f` 的几何反解当作真值，而把接触位置 `p_c` 作为随时间演化的隐状态，用历史 wrench、机器人运动和工具几何共同估计。

### 可部署性
高。KWR75D 已提供所需 6D wrench；第一版可先做解析几何 + EKF/UKF，后续再比较 PF。

### 代码/数据
未核验到官方公开代码；作者研究页公开了该方向的论文脉络和相关成果。

## 2. S+：Robotic Polishing of Unknown-Model Workpieces With Constant Normal Contact Force Control

- 作者：Jian Li, Yisheng Guan, Haowen Chen, Bing Wang, Tao Zhang 等
- 年份：2023（online 2022-11-03）
- 载体：IEEE/ASME Transactions on Mechatronics, 28(2):1093–1103
- DOI：10.1109/TMECH.2022.3216314
- 类型：正式期刊论文
- 推荐优先级：S+

### 核心方法
这是本轮与刮痧任务**最同构**的一篇。它不依赖精确 CAD，而是从工具—工件接触受力中实时估计“当前工具接触姿态”相对“期望表面法向姿态”的偏差，再把简单的 2D 预定义轨迹在线修正成实际 3D 曲面轨迹，同时保持法向恒力。

论文把目标明确写成两个条件：姿态偏差 `phi -> 0`，接触力 `F -> F_d`。工具姿态不沿表面法向时，接触产生的切向/摩擦作用形成接触力矩 `T_c`；作者利用 `omega = T_c × z` 构造旋转修正趋势，每个控制周期生成 `Delta phi` 和 `Delta R`，在线转动工具使主轴重新对齐局部法向。位置方向则根据末端小型主动柔顺机构的伸缩偏差修正宏机器人路径。

实验包含自由曲面木件、不锈钢曲平混合面和铝合金马鞍面；报告表面法向跟踪最大误差约 3°、整体均值约 1.3°，法向力平均误差约 ±1 N。6D F/T 采集为 500 Hz，小型主动执行器控制约 1.3 kHz。

### 对刮痧的迁移
几乎可以直接作为算法 baseline：

- 它的“2D predefined path -> contact-driven 3D actual path”对应我们的“人工画线 -> 3D 背部轨迹”；
- 它的 torque-driven posture correction 对应“视觉法向不准时用 KWR75D 修正刮板姿态”；
- 区别是我们没有 1.3 kHz 的 mini active force actuator，而是 FR5 位置伺服 + 外环导纳；
- 人体是软、时变、摩擦显著的，`T_c` 不能简单全部解释成姿态失配，因此需要视觉先验和软组织/摩擦解耦。

### 可部署性
算法思想高；原硬件结构不能直接复制。建议把其 `contact torque -> Delta R` 作为 FR5 姿态外环 baseline。

## 3. S：Robotic normal constant force polishing of unknown-model workpieces using variable impedance control

- 作者：Lingxiao Li, Bohan Lu, Man Jiang, Lifu Gao, Yuxiang Sun
- 年份：2025
- 载体：Journal of Manufacturing Processes, 153:268–279
- DOI：10.1016/j.jmapro.2025.08.034
- 类型：正式期刊论文；Scopus/WoS 元数据可核验
- 推荐优先级：S

### 核心方法
该工作继续推进未知模型曲面抛光，指出 force fluctuation 的重要来源之一正是**姿态调整本身造成的末端位置扰动**。为此提出基于 contact moments 与 quaternion interpolation 的机器人姿态平滑，并将 variable impedance 参数设计写成受约束的 quadratic programming 问题（QPIC）。

### 对刮痧的迁移
非常重要：如果我们每帧根据 D435/PCA 更新 `n(t)` 并直接重算 `R_d(t)`，法向噪声会转化为姿态抖动，而姿态抖动又会改变刮板接触深度，最终在 `F_n` 中形成二次扰动。因此必须有：

`normal filtering / quaternion smoothing / angular-rate limit`

而不能只滤 F/T。

### 可部署性
高。四元数插值和角速度限制完全适合 FR5 外层轨迹生成；QP variable impedance 可作为第二阶段算法。

## 4. S：Research on Robotic Force Control for Infant Hip Ultrasound

- 作者：Jianwei Cui, Xinyu Zhang, Yuxiang Dai, Wenyi Zhang
- 年份：2026
- 载体：Actuators 15(6):333
- DOI：10.3390/act15060333
- 类型：正式开放获取期刊论文
- 推荐优先级：S

### 核心方法
系统把三个问题明确串起来：**多姿态重力/零偏标定 → torque-based probe pose control → FNN variable admittance**。多姿态静态数据通过最小二乘估计工具重力、CoG、传感器零偏和安装倾角；重力补偿后的 `m_x,m_y,m_z` 用于 PID 姿态闭环，使探头与皮肤贴合；法向力环中，FNN 根据力误差和误差变化率在线调 damping，不要求显式软组织模型。

### 对刮痧的迁移
这篇对 KWR75D 的**上线前标定流程**非常实用。我们以后不能只做一次空载 `zero()`，而应建立多姿态 gravity/CoG/bias calibration。否则刮板姿态变化时，工具重力矩会被误认为皮肤接触力矩，直接污染 `contact point` 和 `normal correction`。

### 实验结果
phantom 与 human skin 的力波动幅值约 0.098 N，稳态绝对力误差低于 0.01 N；还做了初步 infant experiment。

### 可部署性
很高。多姿态最小二乘标定可优先在 FR5+KWR75D 上复现；FNN 可后置。

## 5. A+：Preliminary Research on Autonomous Robotic System for DDH Ultrasound Examination

- 作者：Jianwei Cui, Yuxiang Dai, Xinyu Zhang, Yao Xiong, Wenyi Zhang
- 年份：2026-08-16
- 载体：Actuators 15(8):446
- DOI：10.3390/act15080446
- 类型：正式开放获取期刊论文
- 推荐优先级：A+

### 核心方法与工程数据
硬件由 6-DoF 机器人、六维 F/T、RGB-D、超声探头组成。F/T 以 **100 Hz** 采集，导纳外环实际只跑 **50 Hz**；切向沿规划轨迹，法向由力误差产生位移修正。参数示例：`M=0.25 kg, K=1250 N/m, B=25 N·s/m`。目标力为 -2 N；扫描中均值约 -2.045 ± 0.213 N，RMSE 0.229 N。

系统还采用“操作员在 RGB 图像粗选一个表面点 -> 深度反投影 -> 转机器人基坐标 -> 接触后自主扫描”的流程。

### 对刮痧的迁移
这是非常关键的现实证据：**医疗软接触任务并不必然要求 500–1000 Hz 外环才能工作**。50 Hz admittance + 100 Hz F/T 在低速、低力扫描任务上已有完整系统验证。因此 FR5 如果最终只能稳定做到 50–100 Hz，也不是路线失败；关键是把速度、虚拟参数、滤波、延迟和安全阈值一起设计。

### 安全策略
文中设 6 N 超限暂停/回撤，10 N 终止并回安全位。我们的刮痧状态机也应从第一版就实现硬阈值，而不是等算法成熟再加。

## 6. A+：Force-Based Simultaneous Mapping and Object Reconstruction for Robotic Manipulation

- 作者：João Bimbo, Andrew S. Morgan, Aaron M. Dollar
- 年份：2022
- 载体：IEEE Robotics and Automation Letters 7(2):4749–4756（ICRA 2022 option）
- DOI：10.1109/LRA.2022.3152244
- 类型：正式期刊论文
- 推荐优先级：A+

### 核心方法
当视觉被遮挡时，作者直接用末端 force/torque 求可能接触位置，并通过概率 occupancy map 同时重构环境与抓持物体几何。它证明了“接触本身就是一种几何传感器”。

### 对刮痧的迁移
Eye-in-Hand 最大的问题就是刮板会遮挡真正接触区域。因此我们不应要求视觉始终看到 contact patch：

- D435 负责 look-ahead surface；
- 进入遮挡区后，KWR75D 负责 contact geometry correction；
- 两者在空间/时间上是互补的，而不是要求同一时刻观测同一个点。

这为“视觉前视 + 力觉接触后验”的架构提供了更强理论依据。

## 7. A+：An Admittance Controller with a Jerk Limiter for Position-Controlled Robots

- 作者：Ryusei Mae, Ryo Kikuuwe
- 年份：2024
- 载体：Journal of Robotics and Mechatronics 36(2):483–493
- DOI：10.20965/jrm.2024.p0483
- 类型：正式开放获取期刊论文
- 推荐优先级：A+

### 核心方法
针对 joint-level position controller 存在 deadtime 的机器人，在导纳输出端加入严格离散设计的 jerk limiter；不是简单 heuristic clip，而是从 differential inclusion 出发并用 implicit Euler 离散。UR3e velocity-command mode 实测约 6 ms deadtime，jerk limiter 可抑制刚性接触振荡。

### 对刮痧的迁移
FR5 的 SDK/网络/内部 servo 也会形成不可忽略的延迟。建议控制日志从一开始记录 command timestamp、robot feedback timestamp、F/T timestamp；在普通 admittance baseline 上增加 `v/a/jerk` 限制作为安全层。

## 8. A：Force/Position/Posture Synchronous Control Strategy Research of Robotics Polishing for Freeform Optical Surface

- 作者：Jinlong Dong, Jiashun Shi, Tianqi Zhang, Zixuan Wang, Tianbiao Yu
- 年份：2026
- 载体：International Journal of Precision Engineering and Manufacturing
- DOI：10.1007/s12541-026-01587-5
- 类型：正式期刊论文
- 推荐优先级：A

### 核心方法
针对自由曲面抛光明确提出 **force / position / posture synchronous control**，并设计同步插值算法，使位置、姿态和变力目标沿曲面同步变化。实验在凹抛物面上完成 variable-force polishing。

### 对刮痧的迁移
我们的轨迹点不应该只保存 `p_i`，而应保存统一的 task sample：

`q_i = {s_i, p_i, t_i, n_i, R_i, F_d,i, v_d,i, state_i}`

这样前刮与回程都成为沿弧长 `s` 的同步任务插值，而不是“轨迹节点 + 另一个独立力线程”拼接。

# 本轮结构化精读：Li et al., TMECH 2023

## 研究问题
没有准确 CAD 或装夹存在误差时，预定义机器人轨迹不能保证工具始终沿真实曲面法向接触，更无法稳定维持 normal force。

## 系统与传感器
宏机器人负责大范围 pose；末端 mini-robot/voice-coil 负责高带宽法向主动柔顺；6D F/T 测工具—工件作用力；F/T acquisition 500 Hz，mini force actuator 控制约 1.3 kHz。

## 数学骨架
目标：`phi = 0, F = F_d`。

当工具偏离真实法向时，接触切向/摩擦力产生力矩。论文用接触 torque `T_c` 与工具 z 轴构造姿态修正轴：

`omega = T_c × z`

并在每个周期积分成 `Delta phi`、`Delta R`。因此工具的“真实接触状态”本身成为 surface normal sensor。

位置方面，简单 2D 预定义路径被在线加上沿工具轴的 displacement correction，逐步变成真实 3D surface-following path。法向对齐后 `F_x,F_y -> 0`，于是 `F_n ≈ F_z`，再由直接 PID/主动执行器跟踪 `F_d`。

## 实验
多种未知模型自由曲面、不同材料和力/速度条件；整体法向均值误差约 1.3°，最大约 3°；力控制平均误差约 ±1 N。速度由 2.5 mm/s 增到 5 mm/s 后 normal tracking 误差变差，作者归因于接触振动和宏机器人姿态调整带宽限制。

## 局限
1. 刚性工件，与人体软组织差别大；
2. 有独立高带宽 mini force actuator，而 FR5 当前没有；
3. 接触 torque 的来源相对单纯，刮痧时会混入显著切向摩擦；
4. 没有视觉几何先验；
5. 旋转抛光工具的接触模型与有限宽刮板不同。

## 转化为刮痧论文的创新点
把 `T_c -> Delta R` 从确定性比例修正升级为**视觉—wrench 多模态接触姿态估计**：

`n_v = RGB-D local normal`

`zeta_w = {F_n, F_t, tau, p_c}`

`n_hat = estimator(n_v, zeta_w, motion history)`

再将 `n_hat` 同时用于：

- 法向导纳方向；
- scraper orientation；
- contact-frame 更新；
- 前刮/回程不同 force-speed profile。

这比单纯“视觉算 normal + admittance”更有算法贡献。

# 对总体技术路线的本轮修正

## 1. 第一版状态估计应从“法向估计器”升级为“刮板接触状态估计器”
建议最小状态：

`x_c = [n, p_c, e_edge, F_n, F_t, tau_t]`

其中 `p_c` 为等效接触位置，`e_edge` 表示刮板偏载程度。D435 主要观测 `n` 的几何先验；KWR75D 主要观测接触后验。

## 2. 视觉和力觉应是多率融合
视觉 15–30 Hz 足以做 look-ahead geometry；F/T 应尽量高频。不要强行把两者同步成同一控制频率。可以让视觉状态保持/预测，在每个 F/T tick 上更新接触状态。

## 3. 50–100 Hz 外环不是天然不可用
最新医疗机器人实机已有 100 Hz F/T + 50 Hz admittance 的低速软接触扫描验证。FR5 第一阶段目标应是先测清真实延迟和稳定域，而不是先假设必须 500 Hz。

## 4. 轨迹数据结构应同时包含 position / posture / force / speed / state
人工画线三维化后不要只输出 XYZ；应输出沿弧长同步任务序列，以便前刮恒力、转向降速/降力、轻力回程都能连续插值。

# 已有文献支撑 vs 待验证工程假设

## 已有较强文献支撑
- 6D wrench + 工具几何可用于接触位置推断；
- 接触 torque 可用于未知曲面工具姿态/法向修正；
- RGB-D 法向存在明显误差，F/T 可用于接触后修正；
- 位置控制机器人可做外环 admittance，但 deadtime/带宽必须显式处理；
- 50 Hz 级外环在低速软组织医疗扫描中可以工作；
- 姿态变化与 force loop 是耦合的，需要平滑姿态更新。

## 仍需我们自己实验验证
- KWR75D 的 torque resolution 是否足以稳定区分刮板左/右偏载；
- 刮板有限宽度线/面接触时，point-contact wrench-axis 模型偏差有多大；
- 皮肤摩擦造成的 torque 与姿态失配 torque 能否通过运动方向、视觉法向和时序模型分离；
- D435 在刮板遮挡、皮肤纹理和近距离深度条件下的 look-ahead normal 精度；
- FR5 `fairino-python-sdk` 的真实 Cartesian command/feedback latency、jitter 和稳定更新率；
- 前刮与轻力回程的安全 `F_d-v_d` 参数范围。

# 下一轮自适应检索方向

1. **contact line / center-of-pressure / distributed contact**：专门寻找宽工具、刮板、砂带、抛光盘在 6D wrench 下从点接触扩展到线/面接触的可观测性与估计方法；
2. **FR5/位置伺服外环的离散稳定域**：进一步追 passivity、sample-and-hold、delay margin、energy tank、jerk/velocity limiting，并转成可用于实验参数选择的条件；
3. **Eye-in-Hand look-ahead surface modeling**：重点跟进 2026 年实时 quadratic local-surface modeling、multi-view point cloud fusion 与 arbitrary tilt tracking，寻找单 D435 可复现版本。

RL 继续保持后置，直到接触状态、基础柔顺和实机带宽被测清。
