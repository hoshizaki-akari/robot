# 刮痧机器人项目路线图（项目级事实来源）
最后更新：2026-10-10（Run 13；研究报告/资料审计，未做实机试验）
状态：研究与系统架构规划；未声称硬件 G0 或人体接触实验已经通过。

## 0. 项目目标与原则

目标是构建一套可复现的机器人刮痧系统：用 Eye-in-Hand RGB-D 获取背部/软体曲面几何，把操作者绘制的二维线条转换为三维曲面轨迹，估计刮板接触状态，并安全、可验证地完成前刮、转向和轻力回程。

1. 不从零重造所有算法。成熟模块使用可信 baseline，创新资源集中在有实验依据的瓶颈。
2. 先证明硬件、接口和传感器可用，再比较控制算法。
3. 跨任务论文结果不能直接当成本项目性能；迁移假设须用体模/工装验证。
4. 核心创新在完成最近邻相关工作比较前，只标记为“候选假设”。
5. 人体测试须在适当风险评估、审批/伦理和明确停止标准下进行；当前以工装和体模为先。
6. 将文献支持、工程推断、本机待测和不适用证据分开记录。

## 1. 端到端系统架构

RGB-D + 人工标线
→ camera/robot/tool calibration
→ surface geometry + confidence
→ 2D stroke lifting / surface-constrained 3D path
→ wrench compensation + full wrench transform
→ contact estimator: Fn/Ft/equivalent CoP/edge-load/confidence
→ time-varying contact frame
→ bounded force-position/admittance controller
→ Forward / Turn / LightReturn FSM
→ independent safety supervisor + timestamped logging。

学习方法只能在安全 baseline 稳定后作为低维参数提议器；不得直接输出任意 6-DoF 位姿或绕过安全监督。

## 3. Baseline 矩阵

| 模块 | 简单 baseline | 强 baseline/候选 | 本项目必须验证的事 | 退出/替代条件 |
|---|---|---|---|---|
| 相机-机器人-工具标定 | 标准手眼标定 + 独立几何验证 | Hydra / 其他开源标定方法，按传感器和机器人适配性筛选 | 安装几何、参考点残差、多姿态鲁棒性 | 无法满足误差预算时改进治具/标定方法 |
| RGB-D 曲面 | 深度反投影 + 局部平面/二次曲面拟合 | 局部 patch tracking / 多视角配准 / 非刚性慢层更新 | 法向角、曲面距离、无效深度、延迟 | 若算力/延迟过大，保留局部几何与置信度，停用实时复杂重建 |
| 二维线→三维路径 | RGB 线检测 + 深度反投影 + 曲面投影 + B-spline/弧长采样 | 网格参数化或曲面约束优化 | 独立三维参考曲线及误差分解 | 深度/表面置信度不足时暂停、重采或人工确认 |
| F/T 净化 | 原始 wrench + 静态 bias | 重力/CoG、动态惯性、坐标与参考点完整 wrench 变换 | 六轴响应、符号、单位、漂移、重复性 | 通道异常或误差超预算，不得用于闭环 |
| 接触估计 | CAD 工具几何 + wrench 解析 CoP/等效作用点 | 视觉先验 + wrench + 运动方向/置信度融合 | 接触位置/边缘载荷真值、摩擦与软形变下的可观测性 | 不可观测时增加触觉或缩减估计声明 |
| 表面恒力控制 | 有界固定参数导纳 | Direct adaptive admittance；接口支持时将显式力/力矩控制作为平台相关上界参照 | 真实反馈率、命令时延/抖动、相位、超调、峰值力、脱接触 | 接口/带宽不满足时放慢动作或评估经验证的原生模式/被动柔顺 |
| 状态机和安全 | 可审计 FSM + 限速/限力/异常退出 | 状态相关参数与安全过滤器 | 转向/回程冲击、转换逻辑、停止时间 | 风险路径未验证，不进入人体接触 |
| 学习层 | 不学习；固定基线 | 低维 residual/offline RL | 安全数据覆盖及相对基线增益 | 前置 Gates 未过，禁止加入 |

## 4. 创新候选（不是既成结论）

### H1：接触置信度驱动的动态 contact frame + 有界柔顺控制
在软表面和滑动摩擦造成视觉法向与 wrench 力矩均不确定的条件下，按接触状态置信度更新等效 contact frame，并用有界、时延感知的柔顺控制保持轨迹和接触。必须证明与已有接触感知、自适应导纳和显式力控的机制差异与新增价值。

可证伪条件：若 CoP/接触状态误差未优于固定接触点，或动态 contact frame 没有改善同条件测试中的力峰值、接触连续性和路径误差，则撤回或收窄 H1。

### H2：人工二维标线到三维软曲面的可信轨迹重建
面向深度无效、遮挡和局部形变，用曲面约束与置信度传播降低路径失败。如果接触控制被硬件接口限制，H2 可作为算法方向备选，但需做近邻工作检索和三维真值评估。

### 不作为当前创新宣称
标准手眼标定、B-spline 平滑、状态机、标准导纳、ROS 2 集成、多传感器堆叠或直接套用强化学习。除非提出明确新机制并由强基线、消融和真值实验证明，否则不单独作为原创贡献。

## 5. 模块接口合同（逐步落实到代码和测试）

每个消息至少记录 timestamp、frame_id、units、valid、confidence 和 source_version。不能把消息到达时间冒充传感器采样时间。

- SurfacePatch：曲面/局部点云、法向、可靠时的曲率、置信度和采样时间。
- Stroke3D：带 frame 的三维轨迹、弧长参数、法向先验、点级置信度/无效标记。
- WrenchRaw：六维原始数据、传感器 frame、参考点、原始单位、采样时间和设备/驱动版本。
- WrenchCompensated：bias/重力/惯性补偿后的 wrench、滤波版本和质量标记。
- ContactState：Fn、Ft、等效 CoP、边缘偏载、视觉法向/接触法向/工具法向、协方差或置信度、valid 标志。
- ContactFrame：当前接触点和方向、接触点速度、更新原因、版本与跳变/拒绝标志。
- MotionCommand：目标轨迹/速度/受限修正、命令时间戳、有效期限或序号。
- SafetyState：正常/限速/暂停/释放/停止、触发原因和锁存状态；安全监督不依赖学习层批准。

任何 wrench 变换都要写清表达框架和参考点；任何力目标都要写明作用轴、坐标系和单位。公共接口变化必须同步更新架构文档和测试。

## 6. 最小实验系列

### E0 数据链健康
已知静载/力臂逐轴加载、独立参考测力、静态 bias/温漂、原始帧完整性与时间戳。输出逐轴比例/符号/重复性、偏置和时间质量。未通过则停止。

### E1 命令—实际运动
在安全无接触状态下做小幅正弦/阶跃；记录发令、实际位姿、状态更新和丢包。计算更新率、延迟、抖动、增益与相位。具体振幅/频率/停止限制以现场规格和风险审查为准。

### E2 运动环到接触力响应
仅在 E0/E1 和独立停止机制通过后，在软体体模做受控小扰动；统一比较固定导纳和候选控制。记录目标/实测力、峰值/超调、RMS、相位、脱接触率、转向冲击和停止响应。

### E3 CoP/contact-frame 可观测性
使用已知曲率工装、已知工具几何、已知载荷位置与独立接触位置参考，改变接触点/板倾角/切向运动方向。比较解析 CoP、动态 frame 和视觉先验融合，报告误差、误更新率及低置信度退化行为。

### E4 2D→3D 路径
制作已知三维曲线参考，比较像素深度反投影、曲面投影与可选参数化方法；分解相机、手眼、深度、曲面拟合和轨迹平滑误差。

## 7. 文档与版本控制工作流

项目文档作为长期事实来源：
- PROJECT_CHARTER.md：目标、范围、非目标和硬件约束。
- project_roadmap.md：系统路线、Gates、baseline 和实验。
- BASELINE_MATRIX.md：证据、适配性、代码和对照定义。
- DECISION_LOG.md：决策、反证、变更影响。
- EXPERIMENT_PLAN.md：真值、条件、指标和验收门槛。
- STATUS.md：进度、阻塞项和下一项工作。
- AGENTS.md：让大模型每次开发前读取架构/接口、跑测试、更新状态，不擅改公共合同。

每轮研究：读已有报告 → 明确最多三个决策问题 → 检索核验 → 设计对照实验 → 更新路线或写明不变原因 → 新分支新增报告 → 回读检查 → PR。未经授权不合并。
